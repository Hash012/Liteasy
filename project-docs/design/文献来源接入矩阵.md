# 文献来源接入矩阵

## 接入原则

- 只接公开 API、公开协议（例如 REST / OAI-PMH），或已签署的商业授权；不得把页面抓取伪装成正式数据源。
- `可发现`、`有元数据`、`有引文图`、`可合法打开全文`、`可下载 PDF` 是五项独立能力。前端只能对最后一项显示“阅读全文 / 加入文献库”。
- 每条记录保留来源标识、来源记录链接、检索词和关系类型；同 DOI 或同 arXiv 标识先合并，再排序。
- 服务端用统一 provider registry 编排来源启用、检索、失败隔离与结果合并；客户端用穷尽的 provider contract 校验来源身份和记录链接。新增来源不能绕过这两层边界。

## 锚点本地权威词表

- 数据集/指标锚点先做严格名称匹配，目前只覆盖 BLEU、ROUGE、ImageNet、GLUE、SQuAD 的提出论文；命中后直接写入同一份锚点关联图，不发起网络检索，也不占外部检索配额。
- F1、AUC、accuracy 等歧义指标没有唯一提出论文，不进入权威词表；部分匹配（例如 `BLEU-like`）也不命中，避免以“权威”名义制造错误关系。
- 权威词表只表达“已知数据集或指标的提出论文”，不伪装为当前论文的作者亲引关系；界面以独立可信度来源展示。
- 论断锚点可以保留为阅读标记，但不会自动检索“支持/反驳论文”。该关系必须经过独立的命题与证据验证流程后才能进入产品。

## 中文来源：P0，等待正式接入条件

| 来源 | 目标覆盖 | 目前状态 | 上线条件 |
| --- | --- | --- | --- |
| PubScholar | 中文科技论文、学位论文、预印本、图书与数据 | 待正式接口/数据授权确认 | 获得官方 API、导出协议或合作授权；补充字段映射与契约测试 |
| 国家哲学社会科学文献中心 | 中文人文社科期刊、古籍及相关资源 | 官方通知确认存在“API 用户”通道，但未找到公开接口契约 | 获得机构/API 用户资格与正式接口文档；使用当前 `.cn` 域名为正式来源标识 |
| ChinaXiv | 中文预印本 | 待接口核验 | 核验公开接口或 OAI-PMH，并验证 PDF 链接 |
| 中国科技论文在线 | 中文预印本与科技论文 | 待接口核验 | 核验公开接口或合作授权 |

上述“待确认”不进入在线检索结果，也不产生伪造的全文按钮。可先由 OpenAIRE、CORE、BASE 等聚合来源补充高校机构仓储中的开放记录，但仍要保留原始仓储的来源信息。

截至 2026-08-01，PubScholar 官方站可以确认平台与运营主体，但没有检索到可据以开发的公开 API 文档；这不等同于断言其不存在合作接口。国家哲学社会科学文献中心原 `nssd.cn` 的官方迁移通知明确提到“API 用户”可继续使用文献资源，但当前公开帮助页只说明注册、检索、在线阅读和下载流程。两者均不得通过模拟网页请求进入生产检索。

## 解析与离线评测核验

- 自 2026-02-13 起 OpenAlex 所有 API 请求均要求 key。生产部署只从服务端 `OPENALEX_API_KEY` 读取，客户端请求只表达是否需要 OpenAlex 能力；设置页不收集用户 key，服务接口也不接受浏览器传入 key。
- GROBID 暂不作为终端产品依赖，也不在普通用户设置中开放 PDF 上传。桌面端默认且当前固定使用本地数字编码与作者-年份规则；服务端解析接口保留为以后受控部署的可选实验能力，用户电脑无需安装 GROBID。
- 2026-08-01 使用部署 key 完成官方实时关系 smoke：`W3177828909 cites_target W2963341956` 通过。修复前的固定检索样本共 12 条路径、45 条候选和 12 条 OA 全文；3 条中文直检为空，且没有明确引用图关系。该历史样本只证明当时的密钥与连接器可用，不构成相关率质量门通过。
- 产品检索现在对中文锚点最多提交两条查询：优先使用模型返回的受约束英文检索词或本地学术词表翻译，同时保留中文原词；服务端并行检索并按稳定身份去重。评测脚本仍分别记录 direct / translated 路径，以便发现回归，而不是把两条路径的结果混成一个分数。
- 锚点局部参考文献先在目标论文 `referenced_works` 的闭集中严格匹配；闭集缺项时可调用 OpenAlex 搜索，但搜索命中仍必须通过题名、年份和作者校验后才能进入引文图。解析数量和未匹配条目会写入质量门样本，避免“关系为零”只能靠猜测定位。
- 上述中文双路和局部引用恢复改动完成后，需要在实际部署 key 下重新生成 protocol v2 样本并完成人工相关性标注，才能宣布质量门通过；旧版已标注工作表不得替代本轮验收。
- P0 修复后的 protocol v2 实时样本已在 2026-08-01 重新生成：7 个来源启用，12 条路径均无网络失败，共 45 条候选、13 条 OA 全文。严格锚点引用从 0 恢复为 1 条；另有 1 条主题结果带引文计数元数据。三条中文直接检索仍为空，三条英文改写路径各返回 5 条，因此产品使用“英文改写优先 + 中文原词兜底”的合并请求，评测保留两路作为诊断。
- 实时复测还暴露并修复了响应体长尾：OpenAlex/arXiv 的超时现在覆盖响应头和完整正文解析，单个上游在返回响应头后停滞不会再无限挂起整个检索批次。
- 新样本中有 25 条与历史工作表满足“同锚点、同稳定来源 ID、同标题”的严格身份一致条件，打标工具沿用了这些既有人工判断并记录来源；其余 20 条已完成人工判断，45 条均无空标签。
- protocol v2 最终质量门已通过：正式产品路径的锚点 top-5 平均相关率 73.3%，人文社科 80%，中文先译再检索 73.3%，引用图可得 4.4%（2/45），OA 全文可得 28.9%（13/45）。中文直接检索对照组仍报告 0%，但同一锚点存在翻译路径时不再作为额外的独立产品锚点计入总体平均；实际产品提交的是翻译优先、原词兜底的合并请求。
- GROBID 的 `/v1/research/parse-pdf` 实验接口仍保留：只有受控构建显式传入解析授权时才发送原始 PDF；服务端按 SHA-256 复用 TEI，只持久化 TEI 与解析器版本，不持久化 PDF。当前普通桌面产品不会传入该授权，因此始终使用本地数字编码与作者-年份解析。
- `teiCoordinates` 必须按 GROBID 官方接口作为多个同名 multipart 字段提交（`ref`、`biblStruct`、`note`），不能逗号拼成一个字段；实现与契约测试已按[官方 PDF 坐标说明](https://grobid.readthedocs.io/en/latest/Coordinates-in-PDF/)固定。
- GROBID 官方提供独立、稳定的端到端评测集和运行脚本，覆盖 PMC、bioRxiv、PLOS、eLife 等 PDF/XML 对；可用于验证 PDF 到 TEI 的引用、参考文献和正文结构抽取。
- 官方明确指出全文结构标注尚不完全一致，不能把其公开基准直接解释为本产品在中文、人文社科或脚注式文献上的准确率。上线门仍需使用本项目固定样本，在实际部署配置上复测。
- OpenAlex 提供免费季度全量快照；Semantic Scholar Datasets API 提供全量发布和增量差分；Crossref 提供年度公共数据文件。它们可以支撑离线候选生成、引用图覆盖统计和回归复现，减少在线 API 消耗。
- 上述快照没有“某个正文锚点的 top-5 是否相关”的人工标签。产品验证仍需单建中英文锚点标注集，并把人文社科、脚注式引用、无 DOI 和扫描件分层统计。

## 下一轮接入顺序

1. 向 PubScholar 与国家哲学社会科学文献中心确认机器访问、速率、字段、全文许可与缓存条件。
2. 为每个获准来源提交固定样本的契约测试：中文题名、作者、年份、摘要、永久记录链接、OA PDF 链接。
3. 接入 ChinaXiv 与中国科技论文在线；再接 CORE、BASE、DOAB、ERIC、RePEc、OSF/SocArXiv/PsyArXiv、PhilPapers。
4. 建立中英文人文社科标注集，分别度量锚点 top-5 相关率、引文图覆盖率、OA PDF 可得率与中文锚点命中率；未达门槛不扩张 UI。
