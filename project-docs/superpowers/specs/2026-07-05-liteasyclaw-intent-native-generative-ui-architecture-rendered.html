LiteasyClaw 意图原生生成式 UI 中文 Mermaid 架构图

打开此 HTML 后，Mermaid 会在浏览器中渲染下方架构图。若离线环境无法访问 CDN，可使用同目录 .mmd 源文件在 Mermaid Live Editor 或本地 mermaid-cli 渲染。

flowchart TB
  %% LiteasyClaw 意图原生生成式 UI 详细架构图
  %% 核心原则：用户表达自由，模型输出结构化，执行与渲染受控。

  User["用户
自然语言 / 语音 / 默认 UI 事件"]

  subgraph InputLayer["一、输入与上下文层"]
    InputAdapter["Intent Input Adapter
统一文本、语音、按钮、自动化事件"]
    ContextBuilder["Context Builder
构造 PlannerContext 与 PolicyContext"]
    ContextPanel["右栏 Context Panel
展示选中文献集、导入、云账号、组织、画像状态"]
  end

  subgraph ContractLayer["二、契约注册层：系统能做什么"]
    CapabilityRegistry["Capability / Action Registry
layout、theme、panel、artifact、settings、organization"]
    ActionCatalog["细粒度 Action Catalog
pane.focus、layout.set_ratio、artifact.open_tab、recommendation.refresh、collection.add"]
    ComponentRegistry["Component Registry
StatusBanner、EvidenceCard、ActionBar、ArtifactLauncher、ComparisonTable"]
    DataSourceRegistry["DataSource Registry
selected set、citations、artifact tasks、workspace、profile、organization"]
    TokenRegistry["Design Token Registry
颜色、密度、间距、字号、语气 preset"]
  end

  subgraph IntentRuntime["三、意图运行时：理解目标但不直接执行"]
    ModeGate["Mode Gate
command 可执行动作
qa/explain 只展示证据与非破坏性产物入口"]
    SemanticPlanner["Semantic Planner
规则 planner + DeepSeek/OpenAI 结构化 planner"]
    IntentPlan["IntentPlan / SemanticActionPlan
intentId、actions、risk、requiredContext、summary"]
    PlanValidator["Plan Validator
校验 actionId、schema、上下文需求、模式边界"]
  end

  subgraph PolicyLayer["四、策略闸门：确定性裁决"]
    PolicyEngine["Policy Engine
权限、风险、可逆性、成本、隐私、确认规则"]
    HumanConfirm["Human Confirmation UI
高风险 / 中风险动作人工确认"]
    Clarify["Clarification / Recovery
缺上下文、歧义、不可支持时给出恢复路径"]
    SmoothPolicy["丝滑执行策略
低风险即时执行、长任务后台化、失败可恢复"]
  end

  subgraph ExecutionLayer["五、受控执行与状态层"]
    Executor["Transactional Executor
只执行 policy 允许的注册 action"]
    ProgressEvents["Runtime Progress Events
plan_preview、progress_started、task_created、ui_dsl_ready、action_failed"]
    AppControllers["App Controllers / State Kernel
工作区、选择集、artifact、组织、设置、布局真实状态"]
    Journal["Execution Journal
traceId、输入、计划、策略、执行、UI DSL、用户点击可回放"]
  end

  subgraph GenUILayer["六、生成式 UI 运行时：声明式投影"]
    UIDslGenerator["UI DSL Generator
规则生成优先，模型生成受 schema 限制"]
    UIDslDoc["UIDslDocument
root、dataSources、actions、audit、traceId"]
    DSLValidator["DSL Validator
拒绝未知组件、未知 action、非法 props、任意 CSS"]
    UXValidator["UX Validator
遮挡、弹窗叠加、按钮不可达、证据矛盾、认知负担"]
    FallbackUI["Fallback UI
模型失败、DSL 错误、UX 风险、策略拒绝时保持可用"]
  end

  subgraph RenderLayer["七、渲染与交互层"]
    AssistantCanvas["右栏 Dynamic Canvas
计划摘要、证据卡、动作条、状态反馈"]
    ArtifactCanvas["中心栏 Artifact Canvas
思维导图、树形展开、PPT、对比表、证据矩阵"]
    WorkbenchOverlay["工作台 Overlay / Layout Projection
布局、主题、面板状态的可解释反馈"]
    ActionRouter["ActionRef Router
动态按钮只产生 ActionRef，再回到策略闸门"]
  end

  subgraph ModelLayer["模型服务边界：概率性组件"]
    ModelGateway["Model Gateway
DeepSeek / OpenAI / Mock / 云端服务回退"]
    StructuredOutput["Structured Output Adapter
强制 JSON schema，失败重试或降级"]
    AuditModel["Answer / UI Audit Model
解释审计，不改写 journal 事实"]
  end

  %% 主路径
  User --> InputAdapter
  InputAdapter --> ContextBuilder
  ContextBuilder --> ContextPanel
  ContextBuilder --> ModeGate

  ModeGate --> SemanticPlanner
  SemanticPlanner --> ModelGateway
  ModelGateway --> StructuredOutput
  StructuredOutput --> SemanticPlanner
  SemanticPlanner --> IntentPlan

  CapabilityRegistry --> SemanticPlanner
  ActionCatalog --> CapabilityRegistry
  ActionCatalog --> SemanticPlanner
  DataSourceRegistry --> SemanticPlanner
  ComponentRegistry --> UIDslGenerator
  TokenRegistry --> UIDslGenerator

  IntentPlan --> PlanValidator
  PlanValidator --> CapabilityRegistry
  PlanValidator --> PolicyEngine

  PolicyEngine -->|允许 allow| Executor
  PolicyEngine -->|需要确认 confirm| HumanConfirm
  PolicyEngine -->|拒绝/澄清 deny/clarify| Clarify
  PolicyEngine --> SmoothPolicy
  SmoothPolicy --> ProgressEvents
  HumanConfirm --> Executor
  Clarify --> AssistantCanvas

  Executor --> AppControllers
  Executor --> ProgressEvents
  Executor --> Journal
  ProgressEvents --> AssistantCanvas
  ProgressEvents --> ArtifactCanvas
  AppControllers --> UIDslGenerator
  IntentPlan --> UIDslGenerator

  UIDslGenerator --> ModelGateway
  UIDslGenerator --> UIDslDoc
  UIDslDoc --> DSLValidator
  DSLValidator --> UXValidator
  UXValidator -->|通过 pass| AssistantCanvas
  UXValidator -->|中心产物| ArtifactCanvas
  UXValidator -->|工作台反馈| WorkbenchOverlay
  UXValidator -->|失败 fallback| FallbackUI

  AssistantCanvas --> ActionRouter
  ArtifactCanvas --> ActionRouter
  WorkbenchOverlay --> ActionRouter
  ActionRouter --> PolicyEngine
  ActionRouter --> Journal

  Journal --> AuditModel
  AuditModel --> AssistantCanvas
