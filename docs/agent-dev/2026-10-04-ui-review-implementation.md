## 保留行为

- 不迁移或重写文件、元信息存储模型、锚点或 AI 材料范围。
- 设置搜索和分类切换继续保持表单挂载，不丢弃模型连接等未保存输入。
- 右键和底栏的“编辑元信息”仍直接进入编辑态；无错误时保存反馈在本地面板呈现。
- 自由分栏、关闭、拖动、键盘移动和原有布局预设保留；本次不自动清空其他面板来制造“专注设置”。
