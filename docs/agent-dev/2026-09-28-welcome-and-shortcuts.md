# 开始页、主题标志与基础快捷键

## 用户可见变化

- 用透明 SVG 组件重绘现有书本与环形品牌标志，继承主题颜色。中间栏和其他空面板均不再显示带浅色背景的 JPG，也不使用会影响其他内容颜色的图片反相滤镜。
- 中间栏没有标签时显示低对比度品牌标志、可点击的文献库/AI 对话/设置/指南入口，配套功能图标、简短说明及快捷键。其他空面板只显示紧凑标志。关闭中间栏内容后开始页自动返回，窄栏允许说明换行和纵向滚动。
- 文献库入口聚焦搜索框，并说明导入文件、双击阅读；AI 入口打开用户实际放置的聊天栏并聚焦输入框，不清除草稿；设置入口保持中间栏打开行为。
- 内置离线帮助新增入门说明，覆盖文件导入、单击选中/双击阅读、附件计数、标签筛选、模型连接、首次对话、上下文引用和顶栏 AI 工作台。
- 桌面应用版本统一升级至 `0.1.21`，高于已生成的 `0.1.20` 安装包；仅更新应用自身版本，不升级依赖。

## 快捷键与约束

| 功能 | Windows / Linux | macOS |
| --- | --- | --- |
| 打开文献库 | Ctrl+Shift+L | Command+Shift+L |
| 开始 AI 对话 | Ctrl+Alt+I | Command+Option+I |
| 打开设置 | Ctrl+, | Command+, |
| 查看帮助 | F1 | F1 |
| 搜索快捷操作 | Ctrl+Shift+P | Command+Shift+P |

绑定、开始页提示、活动栏悬浮提示及帮助快捷键表共用命令目录。快捷操作支持搜索、方向键选择、Enter 执行和 Esc 关闭。

控制器忽略已处理事件、组合输入、按键重复和 AltGraph，不截获单字符输入。账号、导入、元数据等模态框打开时暂停工作台导航，避免在弹窗背后切换面板。打开已移动或已关闭的 AI 面板仍复用 Dock 导航与持久会话。原 F1 帮助监听在 AppShell 中关闭，交由统一控制器注册，避免重复执行。
