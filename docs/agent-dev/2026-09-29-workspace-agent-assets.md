# 工作区 Agent 与按需资产上下文

## 用户路径

- PDF 选文菜单按实际尺寸定位，颜色与操作分组；阅读模式复用相同操作组件。
- 输入框的“添加上下文”可按部分名称查找资产，预览后直接加入。新建的笔记、内部白板和已挂载 Markdown 文件可以作为工作目标。
- 普通对话使用可执行的资产工具循环：模型选择查找、读取、写入或答复，应用执行并返回真实结果。附加对象不再绕过 Manager 进入纯问答。
- 例如将 Cicada 要义写入 CicN：查找相关论文、按需读取来源、读取目标笔记、携带读取版本写入、显示保存回执。回执可打开实际编辑器。
- 工作记录默认收起，展示当前操作与耗时；展开可看工具结果。服务商的原始 reasoning 字段不再当成“公开推理”呈现。

## 统一资产能力

`AgentAssetAdapter` 定义 `search / stat / read / write / context / resolveImages`。注册适配器即可扩展类型，声明的 capabilities 决定可用操作；界面和模型使用同一 Liteasy Path 定位。

- 内部 Markdown 笔记：真实持久化读写、历史版本、项目索引更新。
- 内部白板：读取 JSON Canvas，验证后通过现有白板事务替换；保留未修改的引用，修改卡片生成派生笔记，不改动原始论文。
- 外部 Markdown：通过现有挂载文件服务和 expectedVersion 写入；保留 Obsidian 编辑提醒。
- 原论文、提取材料与生成产物：可发现、读取、加入上下文；原始资料只读。外部 Canvas 和生成产物的通用写入尚未开放，仍使用对应编辑器的保存路径。

固定 revision 和 selector 在读取中保持；写入必须使用读到的版本。更改期间发生冲突会报告失败，不默默覆盖。取消与提交竞态发生时，已提交的修改仍发出 `asset.written`，持久化并显示保存回执。

## 上下文与预算

普通问候只发一次简短模型请求，不枚举或读取文库。其他任务初始只提供附加资产、选中论文的题录和已有摘要；正文、分页和图片由模型按需读取。缺失摘要或只有已缓存页面时明确说明覆盖范围。

`assistant.context_window` 设置输入上下文预算，默认 32768 tokens，可在 AI 设置调整。界面显示当前请求占用估算与上限；估算包括指令、结构化协议、历史、已读材料和图片余量，不冒充服务商的精确 token 计数或模型官方窗口。请求预留输出空间；服务商自身的输出上限仍由其接入配置决定。

超预算时优先移出旧对话及较早读取正文，保留操作回执和修订信息；仍超出则停止下一次模型请求，明确已保存与未完成状态。工具循环有次数上限。图片二进制不进入活动记录、读取元数据或持久化快照。

资料是数据，不能自行授权修改；应用根据用户本轮请求开放写入，禁止猜测路径，要求读取目标和匹配版本。整体替换必须完整读取目标，允许分页累计覆盖；追加保留已有正文。

## 验证入口

- `workspaceAgent.test.ts`：CicN 完整执行路径、Manager 不被附加上下文绕过、问候无工具调用、拒绝未经请求的写入。
- `workspaceAgentSafety.test.ts`：取消后的提交回执、预算、猜测路径、只读来源。
- `agentAssetService.test.ts`：真实对象/文件/白板存储、旧版本与选区、冲突、索引、图片和适配器。
- AssistantPane、AgentActivityCard、上下文浏览器和持久化测试覆盖进度、预算、保存回执与兼容读取。
- PDF 选文浏览器回归覆盖浅深色、窄窗口、复制和高亮保存。

模型执行回归使用受控响应来验证实际仓库/文件副作用；不将此结果描述为某个外部付费模型已经完成在线验收。

## 分栏拖动与 0.1.22 交付

旧分隔条在 pointerdown 注册的回调持有初始栏宽，每次增量移动都用初始值重新计算，导致连续拖动无法累积。现在通过 dock 状态引用原子更新相邻两栏，按容器实际可用宽度换算，达到最小宽度时一起限制，保持其他栏尺寸不变。分隔条使用 pointer capture，取消或结束拖动后释放；支持方向键微调。

`dockResizing.test.tsx` 覆盖批量移动、持久化、宽度边界和折叠栏；`paneResizing.browser.spec.ts` 用连续 30 次鼠标移动验证左右栏、下栏高度、下栏分栏以及刷新恢复。此版本一并交付上述 Agent 资产能力和选文菜单修复。Windows 安装包依然必须通过完整 CI 的测试、Release 链接、NSIS、生成文件检查和上传。
