# 文献库分类与图标（0.1.20）

## 修复的问题

Windows 本地快照的目录使用反斜杠路径，论文父目录计算却转成正斜杠后直接查找原始目录索引。因此磁盘上已移入目录的 PDF 仍会显示在文献库根部。目录、父目录和文件现在统一使用路径比较键，兼容盘符大小写、普通路径、Windows 扩展路径及 UNC；不改变文献 ID。

移动路径的比较同样规范化。移动必须先完成原有磁盘调用，成功后才更新工作区；源或目标超出真实本地库时返回错误，不再跳过磁盘操作却宣告成功。位置提示清除 `\\?\` / `//?/` 前缀。原生 Rust 移动及回滚边界保持原有实现。

目录拖放保留蓝色背景、轻微放大与“松开即可移入”反馈。阅读文件和 PDF 使用各自现有的持久化路径；目录移动/重命名同步迁移阅读文件分类和自定义目录图标。

## 图标与布局

- PDF、文本、Markdown、电子书、图片、图片集合、图文、表格、幻灯片、音视频、压缩包等有对应 Fluent 图标；未知格式使用通用文件图标。
- 文件、目录及论文衍生文件右键选择“更换图标”，可搜索 25 个图标，并恢复默认。
- 偏好保存于本机，按账号和文献库隔离。文件使用稳定 ID；目录使用相对路径，并在应用内移动/重命名时迁移。操作系统外部重命名目录不会自动迁移图标。
- 收藏、关联推荐及其余文献库标题的操作按钮与标题同行；图标按钮保留可访问名称和提示，使用主题颜色。
- 版本由 0.1.19 升到 0.1.20，package、锁文件、Cargo 和 Tauri 配置同步。
