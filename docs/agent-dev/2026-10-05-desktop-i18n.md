# 桌面界面多语言接入记录

依据 `tmp/Liteasy-i18n-agent-kit-2026-10-05.zip`，在当前桌面代码上接入语言运行时和核心界面。
本次用户要求优先：新增文案使用中文，其他语言只在用户要求时更新。接入包附带的
初始中英文词条保留；未执行全仓自动翻译，也未更新用户手册。

## 实现边界

- 设置 → 外观与阅读 → 应用界面提供跟随系统 / 简体中文 / English，立即生效并持久化。
- 初次安装跟随系统；已有设置的旧安装默认保留中文。语言存储与 AI/OCR 分离。
- 已迁移活动栏、起始页、快捷操作、设置分类/搜索/注册表、外观控件、字体选择器。
- 语言变化通过组件订阅更新，不刷新页面、不以 locale 重建工作区、不发起模型请求。
- 缺译优先回退中文。新功能使用 `tChinese(key, "中文默认文案", values)`，无需同步修改英文包。
- 检查器以中文为类型源，允许英文缺项；已有译文仍检查参数、完整复数、空值、重复键及 HTML。
- 切换语言仅合并 `view.language`，保留未知设置；损坏数据或写入失败时采用会话选择。
- 英文长设置分类允许换行，窄栏改用水平分类导航。

其余业务页面、部分设置子面板、导览、帮助正文及插件文案保持既有中文。
前端语言不控制系统文件对话框与安装器语言。扩展约定见
[界面语言维护说明](../../products/liteasy/apps/desktop/src/app/shared/i18n/README.md)。

## 依赖

Registry 已确认 `i18next@26.4.2`、`react-i18next@17.0.15` 可用并满足当前 React/TypeScript peer 要求。
真实执行 `npm install --package-lock-only --ignore-scripts` 和 `npm ci`。
锁文件新增上述两项及 `html-parse-stringify@4.0.1`；`@babel/runtime` 从 7.29.2 更新到
7.29.7 以满足 react-i18next 的依赖。TypeScript 仍为 5.9.3，只调整 peer 元数据。
没有升级 React、Vite、Node 或应用版本。
