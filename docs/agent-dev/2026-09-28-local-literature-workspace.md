# 本地文献模式与论文工作区

## 使用入口

- 设置 → 论文推荐：开启「本地文献模式（无需 Liteasy 登录）」。在文献服务中选择 Crossref、OpenAlex 或 Semantic Scholar，填写兼容的 API 地址，需要时保存自己的密钥。服务凭据继续由既有的文献服务传输层管理。
- 本地模式直连配置的文献服务。联网更新推荐，断网或服务出错时保留相同查询的本机缓存。它不提供离线生成模型，也不改变用户已配置的 AI 接入方式。
- 「在本机记录阅读与收藏画像」单独开启，默认关闭，与云端画像开关分离。最多保留 500 条行为，同一天重复打开同一标题合并；从标题汇总至多 24 个研究关键词。可刷新查看、导出 JSON 测试数据或确认清空。
- 单击文献库论文打开阅读器，仍同步显示文件元信息。右键论文可创建有名称的 Markdown 笔记和论文白板；它们显示在该论文展开后的「论文文件」中。
- 双击最左侧文献库按钮打开大浮窗，继续使用同一套搜索、目录和文件操作。打开论文或附件后回到工作区。
- 文件、文件夹及论文附件的「更换图标」支持 Fluent 图标和 Emoji；可粘贴含肤色、组合序列的单个 Emoji。图标仍按账号与文献库保存。

## 持久化与编辑

论文附件复用 `paperProjectRepository` 的项目成员关系和统一对象仓库，不需要先解析 PDF，也不另建临时附件存储。Markdown 笔记在中央区域编辑或阅读，复用 Markdown/公式/图表渲染基础，并按章节渲染预览。保存使用对象版本检查；另一窗口修改相同笔记时拒绝覆盖并保留草稿。切换笔记会保留本轮尚未保存的草稿；退出软件前仍需保存。

本机推荐与反馈使用账号及工作区隔离的有界缓存；每工作区保留最近 8 组检索结果，反馈保留至多 500 个条目标识。切换条件或工作区后取消旧结果写回。推荐保留原有风格排序，数据源返回的年份与引用计数参与排序；展示理由明确是检索匹配，不宣称已经核实引用关系。

## 白板与阅读工具

白板单击选择、双击编辑；空白处双击创建笔记，拖动空白框选，Shift 加选，Ctrl/⌘+A 全选，Delete/Backspace 移除所选卡片。空格或中键拖动平移，Ctrl/⌘+滚轮缩放，Shift+1 适应内容。卡片继续支持拖动、尺寸调整、连接和对话引用；选中状态改为细边框和轻阴影。

交互参照 [Obsidian 官方 Canvas 帮助](https://obsidian.md/help/plugins/canvas)。不是完整复制无限坐标系统：保留现有非负坐标和对象/连接存储格式。

PDF 和论文阅读模式复用选段工具栏：高亮、划线、复制、加入白板、摘录对话、加入对话和速问。速问共用当前页与开篇摘要的请求及批注数据；阅读模式可直接使用批注 AI review。没有可靠 PDF 几何位置的文本不会被猜测为高亮；定位无关的操作仍可引用页码和选段。文本框与手绘保留在 PDF 模式。

界面、论文阅读和电子书阅读使用同一个系统字体选择器，支持搜索和手动输入字体名；长列表最多同时显示 100 项。桌面通过原生命令读取字体；浏览器仅在用户点击后申请字体访问。Windows 使用 [WPF SystemFontFamilies](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.fonts.systemfontfamilies)，Linux 使用 Fontconfig，macOS 使用 AppKit。系统命令参数固定，后台运行，15 秒超时，不下载或安装字体。
