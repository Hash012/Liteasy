# 文献元数据前置与紧凑分类

## 行为变化

- 关联推荐先检查全部选中论文的正式题录。缺少已确认题录时自动读取 PDF 线索、检索并核对；等待期间暂停本地及云端推荐，不把文件名当作题名发出查询。识别有歧义或失败时显示原因，可右键确认身份或刷新重试。已有题录直接复用其正式标题、作者及年份。
- 论文单击选中，双击或 Enter 打开阅读；复选框及 Ctrl/Command 点击保留多选。选中背景适配浅色、深色。
- 论文附件默认折叠，PDF 图标左侧 `+N` 切换展开，不再额外显示“论文文件（N）”标题行。
- PDF、电子书、Markdown 等资产可右键“编辑分类与标签”，设置类别、年份、作者、学科、分类与自定义标签。类别含期刊论文、会议论文、图书、网页、报告、预印本、笔记等；仅凭 PDF 扩展名不会推断为期刊论文。
- 每条资产最多显示四个彩色标签，其余以数量和悬浮说明呈现。PDF 标签可点击筛选；筛选面板支持类别、作者、年份、学科、格式、阅读状态和多个标签交集，并与标题、元数据及文件路径搜索组合。标签选择器显示数量，限制可见项并提供搜索，避免大量标签撑开面板。
- 手动整理字段独立于已确认正式题录，不会因修改标签或分类而改写论文身份。旧数据缺少新字段仍可读取。

## 元数据速度与正确性

PMLR 原流程即使已知 `das24a`，仍可能先读取整卷 bibliography。实际排查中，v235 卷题录约 5 MB；[Larimar 官方论文页](https://proceedings.mlr.press/v235/das24a.html)约 16 KB，并包含官方 BibTeX。

现在结合 PDF 首页的 PMLR 卷号与文件名线索，优先读取单篇官方页面，核对页面的出版者、规范 URL、题名及 BibTeX。文件名仅用于定位，自动确认仍要求正式题录与 PDF 的题名、作者及出版信息相符。刷新已识别、已重命名的论文时复用其 PMLR 标识。找不到合适单篇页才回退整卷题录；缓存单篇与最近一卷，限制数量、大小和有效期。

题录证据新增 `official_article_page`，其摘要是实际获取页面字节的 SHA-256。桌面持久化与 Intuecho 契约均接纳此可选来源种类并约束对应官方 URL，保留原 `official_volume_bibtex`；不把页面内容伪装成卷级文件证据。

请求增加浏览器、Rust 一致的超时与响应体上限：单篇 PMLR 页面 8 秒/512 KiB，卷题录 25 秒/20 MiB，通用题录检索 15 秒/2 MiB，arXiv 每个请求 10 秒/2 MiB。这是单次请求边界，不是整个识别任务的完成时间承诺。外网延迟、扫描 PDF 或缺少可核对题录仍可能需要等待或人工确认。

元数据后台队列最多并行两个任务；重复请求合并，手动请求（包括已排队后台任务的手动重试）优先。排队时保存工作区来源快照，切库后不在新库继续旧任务；进行中的识别仍保留标题、路径和身份变化检查。
