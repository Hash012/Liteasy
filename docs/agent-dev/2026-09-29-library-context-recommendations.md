# 文献库、推荐与 Agent 上下文（0.1.23）

## 用户交互

- 推荐列表仅显示论文标题和已知的发表年月；没有月份时只显示年份，不补造日期。单击把题录投影到底部窄栏，元信息按钮展开作者、刊会、摘要、来源及推荐依据。双击下载实际开放 PDF 到本地文献库 `Download`；无开放全文时报告原因，不把仅题录记录当作下载成功。
- 下载按内容去重、限制响应体积并校验 PDF 文件头。公开 PDF 使用无账号凭据的 HTTPS 请求，逐跳校验重定向；云端推荐沿用有来源约束的全文授权。账号或数据目录在等待期间改变时停止后续写入。已有文献的整理信息不会被推荐记录覆盖。
- 目录每级缩进 18px 并显示引导线。论文附件、电子书及其他已有可读资产使用相同拖放上下文协议；拖到聊天后解析真实资产，不依赖显示名猜测。
- Markdown 笔记、外部 Markdown 和论文提取文本/图文共享可持久化字号设置，阅读和源码编辑均生效。
- Agent 展开步骤展示公开操作说明、真实调用范围与结果摘录。Liteasy Markdown 链接在应用内跳转；显示名取代长地址。等价的已知资产地址可匹配，未知对象、不同账号、选区和版本仍受验证。

## 数据基础

题录增加可选摘要、学科、关键词、刊会和发布日期，读取旧记录兼容；异常可选字段不使原有身份失效。Crossref、OpenAlex、Semantic Scholar、arXiv、PMLR 元信息保留这些字段，必要时从 PDF 明确的摘要段补充。

推荐查询和相关性判断使用完整题录。短名称缺少学科依据时先补元信息；已选论文有主题信息时不再并行执行旧画像中的含糊单词查询。新缓存键包含题录信息并隔离旧的文件名推荐结果。桌面直连实现与正式 API 服务均更新；服务器侧增强需部署该 API 代码才生效。

论文资源组以一个只读引用表示，并保留逐页/图来源。正文支持分页读取；超出 8MiB 明确要求分组，绝不静默截断。大图组保留逐图路径，按需加载；不把图片二进制复制到聊天历史。

## 验证

覆盖推荐种子与同名异域过滤、题录兼容、下载落盘/去重/账号切换、公开下载限制、单击/双击行为、真实对象拖放与分页、字号、Agent 操作和链接跳转。浏览器检查包含浅深色窄列表、EPUB/Markdown 实际拖入上下文、笔记24px阅读与编辑、Agent读写后链接打开与刷新恢复。Rust下载边界测试及 locked 宿主检查通过，桌面生产构建通过；Windows交付仍以完整Installer CI及上传结果为准。
