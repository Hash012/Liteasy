# S15 合成用户任务试点脚本

状态：脚本已准备，未执行真人试点。以下五个角色和文献均为合成内容，不代表已访谈用户、真实社区活动或生产成本结果。只使用独立本地/测试环境与合成账号；不自动发布、邀请真实人员或上传保密资料。

增量的自愿真人分层流程、本地记录工具与失败/未运行统计见 [R11 自愿真人试点准备](qa/review-3188438/R11-voluntary-pilot.md)。它与本合成脚本分别记录；目前没有真人试点或成本测量结果。

## 共同准备

使用一份自制 PDF《合成检索方法比较》：第 1 页写“实验只测 20 个合成问题”；第 2 页先写“正确率 80%”，更正版本改成“16/20，不能外推总体”。准备一条只有标题、无 PDF 的元数据记录，以及仅含这两项的目录。组织名为“合成试点组”，有 owner、admin、member 三类独立测试主体；另有同名但 subject 不同的 A/B 账号。

每次开始前记录测试提交、产品、操作系统、角色、网络条件和数据范围。先确认本机库、本人云收藏、组织文献、Intuecho 受众分别属于谁；账号切换不删除 OS 原件。试点默认本地记录，自愿收集任务结果，不新增遥测 SDK，不记录个人阅读历史、token、密码或正文秘密。

## 五个角色

| 合成角色 | 用户任务 | 检验动作与通过证据 |
| --- | --- | --- |
| 普通阅读者 | 私人阅读后把一项资料交给小组 | 本机导入两项，创建私人批注；打开转移预览，逐项核对来源、组织目标、1 PDF/1 元数据和复制语义。先取消确认无写入，再确认。核对本机批注/派生笔记不会因 PDF 复制而共享；小组内容需按显式受众另行发布。 |
| 初学者 | 能说明“收藏”与“公开”的区别 | 先保存本人云收藏，再从个人 PDF 菜单复制到本机；说明这不是发布到 Intuecho。让其在合成组内分享窗口先选择错误受众再取消，记录能否自主识别目标；不要求公开。 |
| 资深核查者 | 发现并回传一处证据更正 | 在组内指出“80%”仅为 16/20；保留原文定位和更正链。在获得实际确认后，另写本人有权公开的短摘要，只描述合成实验边界，不搬运他人私人回复。核对更正回流是否可追踪；不以自动生成条数计成功。 |
| 组织主持人 | 处理角色变化而不让资产失去主人 | owner 发起邀请后降低邀请者权限，测试接受时以当前授权裁决。转移预览打开期间撤销导出/上传权限，再提交应失败且不显示已共享。尝试删除最后 owner，应先要求交接或处置组织；仅在测试库执行生命周期。 |
| Agent 用户 | 审核自动产物并恢复失败 | 用合成 PDF 生成一份摘要，人工核对 16/20；只允许用户显式提交。离线或换号打断目录上传/发布，确认旧结果不进入 B、旧任务不自动用新身份继续；回到 A 检查部分目标和真实失败状态，明确恢复或撤回。 |

## 每次任务的本地记录

| 字段 | 填写方式 |
| --- | --- |
| task / role / build | 使用上表任务名、合成角色和实际提交；不写真实个人身份。 |
| outcome | `成功`、`失败`、`未运行`、`阻塞`；附实际观察，不把 mock 单测写成 native 通过。 |
| ownership / audience | 用户在执行前说出的来源、目标、可见者，与执行后读取权限结果对照。 |
| recovery / correction | 记录取消、误选、角色变化、离线、换号、重试和更正是否得到真实回执；保存无敏感数据的截图或请求 trace。 |
| reuse | 记录另一合成角色是否实际找到并复用更正/摘要；没有发生就写“未观察到”。 |
| service usage | 仅有实际服务账单/计量时记录请求量、字节、token 和金额，注明计量范围；未接真实 provider 时写“未测”，不从生成数量推算收益。 |
| local retention | 确认本机 PDF、笔记、备份仍由 OS 用户掌握；账号退出/删除不静默删除本机原件。 |

## 结束与真实环境待验

结束后仅清理由本轮创建的合成 fixture。保留测试提交、失败 trace、回执和未完成项；不清空共享开发数据库。生产发送、正式销号、真实邀请与付费 provider 不属于本脚本的自动动作。

尚需真实客户端验证：三平台 keyring 的离线退出和 OAuth 迟到回调；浏览器真实 OIDC 多窗口切号；组织权限变化中的文件保存；实际部署中的删除/撤回日志持续备份及恢复门禁；真实安装器运行结果。隔离 PostgreSQL 的事件前备份恢复另有实测，不能替代真实部署验收。D03 公开正文留存政策未批准变更；个人中心已提供显式选择的本人云资料包导出，范围不含 PDF 字节、本机目录、组织资料或 Intuecho 全账号数据。

实施和已执行测试的边界见 [S01-S02-S13.md](qa/account-cloud-community/S01-S02-S13.md)。本文件不填写虚构的成本、留存、转化或用户研究结论。
