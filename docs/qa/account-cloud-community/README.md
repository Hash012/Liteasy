## 已实现的入口与边界

| 任务 | 可见功能与实现 |
| --- | --- |
| S01–S02 | Desktop/Web/Mobile 保持独立受众。请求、草稿、待处理发布与缓存使用 endpoint、issuer、主体和会话世代隔离；退出不删除 OS 用户的本机原件。无主体归属的旧账号目录保留原件，不能自动认领。 |
| S03–S05 | 分享先选受众并显示实际内容；新普通草稿不默认公开或加入广场。PDF/薄读发布展示冻结的正文、全部证据摘录和作者资料，保存原操作后才发送。资料版本改变须重新确认；结果未知时可只读核实。来源、版本和贡献者信息与权限分开保存。 |
| S06–S09 | Liteasy 是组织成员和权限权威；Intuecho 运行时查询，不复制成员权威。组织选择器显示当前可用组织与拒绝原因，邀请管理支持按权威版本查看与确认撤回；切号、卸载和旧操作回调均受会话栅栏限制。阅读小组支持资料包、问题、定位、讨论、保留异议的主持摘要及个人反思。组织资料的新增公开/外部模型路径保持 D01 HOLD。撤回使用原账本，旧消息不得复活；不声称收回已下载副本。 |
| S10–S11 | 社区页面提供显式订阅、屏蔽、举报/申诉入口及处理记录；通知默认安静，读取时重新鉴权。任务发布与已有参与者提及需明确选择。Liteasy 组织页面提供本人权限变化记录的自愿开启入口。平台治理列表不暴露私人/组织内容或未知旧申诉理由。 |
| S12 | 保留暂存、扫描、配额、幂等与分步修复边界；数据库提交结果未知时不误删已接收的暂存对象。受限源不得因授权服务不可用而降级公开，模型不可静默转用另一付款/授权路径。 |
| S13 | 个人中心可选择本人云产物，预览后导出含清单、来源与修订的 ZIP；每项重新鉴权与核实版本，不含凭据、他人资料、组织附件或未选择内容。生命周期回执包含四类 audience，删除栅栏阻止迟到写入。恢复演练在删除/撤回事件补放完成前阻断业务连接。 |
| S14–S15 | 新增低成本服务 CI，分别建立 Liteasy/Intuecho 的 PostgreSQL 测试库与最小角色，复用原有检查。44 个场景逐项记录证据层次；五类合成用户试点脚本已准备，没有虚构真人研究或成本数据。 |

导出并非全盘备份：当前云资料包不包含 PDF 字节、本机笔记目录、组织资料或 Intuecho 全账号数据；个人云 PDF 沿用显式复制到本机入口。所有导出范围在 UI 与包清单中说明。

## 迁移、回滚和后续验收

本轮新增 Intuecho API 024–027 增量 SQL；Liteasy API 复用并验证现有 28 个迁移，没有改写旧迁移。旧协议的兼容字段保持可选；旧不明归属数据保留，不以新登录账号覆盖。上线前应在独立库备份并验证迁移、权限、删除/撤回账本与恢复结果，再开放业务；不能通过清空账本或反向删除 migration 表来回滚。

代码回滚应保留新增表和列，关闭新增入口后退回兼容代码；删除、撤回和治理审计记录不可回退。恢复较旧备份必须同时具备可信的较新事件账本，并在重放、对账完成前禁止业务账号连接。仓库恢复脚本只用于显式隔离测试实例，不是生产自动运维工具。

D01–D08 仍 HOLD。真实四客户端 IdP 吊销、Windows/macOS/Linux 系统浏览器与凭据链、Android 原生、实际 S3/scanner 故障与生产独立日志持久化尚未验收。Linux 编译、DOM 测试和本地 PostgreSQL 不能替代这些结论；当前实现和 readiness 不等于生产上线批准。
