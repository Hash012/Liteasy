## 已交付范围

| 切片 | 行为与证据入口 |
| --- | --- |
| S01 桌面身份 | `useAccountSession` 对登录、恢复、验证、注销和卸载建立世代栅栏；旧 A 的成功、401、finally 不能覆盖 B。离线、403、5xx 不等同会话吊销。WebDAV 偏好恢复也检查当前世代。 |
| S01 原生凭据 | `desktop_identity.rs` 在同一状态锁下推进世代并提交 keyring；注销先清本机状态和凭据，再远程撤销；锁内不 await 网络。撤销地址来自已校验且绑定 issuer/client 的配置；旧凭据无地址或网络失败只报告远程未确认。 |
| S01 Intuecho Web | OAuth/dev 身份及 community request 共用世代；旧响应与旧 401 无权清新会话。退出先清本机 UI；迟到续期不能重新写回本机 OIDC 会话。composer、conversation、handoff 随身份失效。 |
| S02 本人云与缓存 | 请求捕获 endpoint、已验证 subject、issuer 和会话世代。世代含启动随机值，不能在重启后重复数字 0。缓存键包含 actor 与完整 scope；缺绑定或旧 v1 缓存不归给新账号。 |
| S02 云作用域 | `personalLibraryScopeId` 保留已验证 subject 原值；正式 UUID 不再人为添加 `user:`；开发 subject 原有前缀仍保留。本机路径与 OS 文件归属不改变。 |
| S02 转移 | LibraryPane 现有资源转移、推荐保存、个人 PDF 本机复制入口呈现 Fluent 确认框，固定 source/target 快照并说明来源、目标、复制/同库移动、PDF/仅元数据数量、本机笔记边界和最终权限/配额裁决。controller 的可选 `confirmTransfer` 可供其他入口复用。 |
| S02 多阶段隔离 | transfer 从开始捕获一次 actor，所有云 client 使用同一 binding；权限查询、目录递归、下载/上传、刷新和反馈前后都检查世代。取消无写入；中途换号后不借新身份继续，也不向新 UI 报告成功。本机到本机不需要云登录。 |
| S11 补充 | 组织通知“已读”仅本机且按完整 actor 分区；旧无主缓存不自动迁移。标记已读不接受邀请、不处理任务。 |
| S13 四受众回执 | `account_deletion_jobs.result.identityDeletionReceipt` 存经同一 validator 校验的 subject/status/time 与四受众吊销回执，不存 token。completed、identity_deleted 以及旧 operation 重放均不能从时间戳推定全吊销。旧缺证据记录经现有幂等 adapter 核实；不可用返回 pending retry。 |
| S13 删除后写入 | library mutation/上传准备/补正文/完成发布、personalization、recommendation、Agent artifact 写事务，在 READ COMMITTED 下持有既有 `account-deletion:<subject>` 锁并检查既有删除记录；迟到已鉴权请求不能在这些入口重建私人数据。推荐只读接口不再创建状态。 |
| S13 受控导出 | 个人云 PDF 菜单“复制到本机文献库”复用现有导出流，服务重新鉴权，缺本机库禁用、失败不报成功。**这只是个人 PDF 导出，不是全账号数据包**，不包含跨产品画像/Intuecho 全量数据。 |

S00 核查确认：Liteasy 产品鉴权仍是 JWT + 实时 introspection；Intuecho 保留自己的 audience 边界。正式身份适配器已要求 desktop/mobile/web/admin 四受众，缺口在上层旧恢复分支与文档。组织负责人删除的既有预检保留；不更改 D03 公开正文保留与作者去标识政策，也不宣称删除本机原件或备份已彻底擦除。

## 兼容、保留与未完成

- 未引入新账号/导出账本、迁移、schema、服务角色或宽受众 token。旧删除记录继续使用原 job，缺回执则重新核实；旧无绑定缓存不分配给当前账号。回退 UI 不删除旧缓存、本机原文或操作系统目录。
- 本机凭据清除与远程吊销回执分开；远程离线不会阻止本机退出，也不会声称全设备注销成功。Windows Credential Manager、macOS Keychain、Linux Secret Service 的真实凭据行为及真实 OAuth 多窗口并发仍未验收。
- 目录转移不是跨云/文件系统原子事务。中途失败或换号可能留下原账号已创建的部分目标；不会借新账号清理，不会声称成功或“已共享”。实际服务重新裁决组织权限和配额。
- 转移预览覆盖现有 resource-transfer 入口。原操作系统文件批量导入、库内 OS 文件移动仍走其既有路径；不把它们算作该确认框全部覆盖。本地库更换与已开始 native 写入之间的最终系统调用竞态仍需真实客户端验证。
- 本轮删除栅栏覆盖上述仓库入口，不宣称完成 visualization/device-control 等所有写入审计；备份恢复需要保留并重放既有删除/撤回记录。未执行真实备份恢复演练。
- last-owner 禁止删除与既有阶段恢复已有测试和真实 PG 脚本验证；未提供新的账号自助删除/全账户导出产品流程。公开正文可仍含身份信息，留存政策仍受 D03 决策约束。
- S15 只准备合成脚本，见 [S15-pilot.md](../../S15-pilot.md)。没有真人访谈、生产发送、留存/转化数据或成本收益结论。
