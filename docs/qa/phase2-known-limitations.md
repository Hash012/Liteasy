# Liteasy Phase 2 已知限制日志

本文档记录 Phase 2 当前可验收版本的边界，避免团队成员把开发演示能力误认为正式生产能力。

## 1. 当前阶段已完成的可见能力

- 开发云账号：桌面端可以连接固定演示账号，并在本地恢复会话。
- 云端模型策略：桌面端可以从开发云同步模型接入策略，并按管理员策略限制本地直连入口。
- 文献元数据同步：连接账号后，当前工作区可见文献的基础元数据会同步到开发云演示接口。
- 关联推荐：勾选文献后，左栏可以展示关联推荐，支持按关联度和检索时间排序。
- 收藏：推荐条目可以拖入本地收藏，收藏不会随推荐刷新清空。
- 拖入文献库：推荐或收藏条目可以拖回 `我的文献库`，并进入后续选中、导入、分析流程。
- 问答审计：问答回复会显示原文定位、模型链路、审计模型、审计评分和审计理由。
- 开发云审计接口：当桌面端使用 `http://127.0.0.1:8787` 这类云代理端点时，会优先调用 `/v1/model/audit`。

## 2. 当前仍是演示或 Mock 的部分

- 账号系统是固定演示账号，不包含正式注册、登录、权限、租户或令牌刷新。
- 推荐结果是开发演示数据，不是真实联网检索、召回、去重或排序服务。
- 文献元数据同步只传基础标题、id、路径等信息，不上传 PDF 原文，也不做正式云端文献库。
- `收藏` 是本地持久化，不做云端同步。
- 导入、解析、切块、索引仍是桌面端 mock 流程，不是真实 PDF 解析和向量索引。
- 审计接口已经形成云端链路，但开发云内部仍是确定性规则，不是真正第二个大模型。
- 云端策略、推荐、元数据同步和审计接口都还没有正式鉴权。
- 组织门户、团队协作、管理员后台和插件市场不属于 Phase 2 范围。

## 3. 验收时不要误判的点

- 看到 `开发云回答：` 表示桌面端已经走到了本地开发云服务，但不代表一定调用了真实 OpenAI。
- 如果配置了 `OPENAI_API_KEY`，`/v1/model/generate` 可以走真实 OpenAI；但 `/v1/model/audit` 当前仍是开发云规则审计。
- `文献同步：已同步 2 篇` 表示同步了当前工作区文献元数据，不表示 PDF 文件上传成功。
- 推荐缓存按当前工作区、选中文献集和排序设置复用；工作区内容变化后重新获取推荐是预期行为。
- 推荐或收藏拖入 `我的文献库` 后，只是成为当前桌面原型中的文献条目，不代表文件已复制进真实文件系统目录。

## 4. 下一阶段建议

- 把导入流程替换成真实 PDF 解析、切块和索引任务。
- 为开发云加入最小正式鉴权和会话校验。
- 将 `/v1/model/audit` 替换为真正第二模型或独立审计 provider。
- 将关联推荐替换为真实联网检索、缓存、去重和排序服务。
- 明确本地文献库与云端文献库的数据同步边界。
