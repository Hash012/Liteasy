# LiteasyClaw Phase 3 组织与治理已知限制

本文档记录 Phase 3“组织空间与治理原型交付”的边界，避免团队成员把演示能力误认为正式生产能力。

## 1. 当前已经能演示什么

- 连接开发云账号后，桌面端会请求开发云组织摘要接口。
- 最左侧窄竖栏会显示 `文献库 / 组织 / 个人中心 / 设置` 入口。
- `组织` 会切换左栏为组织页，并可进一步打开 `组织窗口` 原型弹窗。
- `个人中心` 会切换到画像原型面板，可配置性别、年龄、学段，打开学术档案，并走清空画像确认 seam；`设置` 会显示模型接入策略和文献元数据同步。
- 右栏只保留极简 AI 助手对话框，不显示组织空间、组织治理或模型策略卡片。
- 组织页和组织弹窗都包含已加入组织列表，并能在两个 demo 组织之间切换。
- 组织页包含当前组织名称、用户角色、成员数量、成员明细、共享文献库摘要、通知明细、会话级已读状态、配额、任务数量、治理队列和最近审计事件。
- 用户可以点击 `打开共享文献库`，或在命令模式输入 `打开组织共享文献库`，像 VSCode 打开文件夹一样把当前工作区切换为 demo 组织共享文献库；连接云账号本身不会自动打开共享文献库。
- 开发云提供 `/` 服务索引、`/v1/org/list`、`/v1/org/summary`、`/v1/org/governance-summary`、文献元数据同步、模型生成和模型审计接口，用来支撑桌面端原型数据。

## 2. 当前仍是演示数据

- 组织列表固定为 `LiteasyClaw AI Reading Lab` 和 `LiteasyClaw Literature Ops` 两个 demo 组织。
- 当前组织的成员数、成员明细、通知、共享文献库数量、共享文献条目、配额、任务和审计事件都是固定 demo 数据。
- 组织选择只存在于当前桌面会话状态；通知已读状态会写入本机 localStorage，并在点击 `断开云账号` 时清理，但不会同步到云端或跨设备变化；已读 key 已按 `organizationId:notificationId` 隔离，避免不同组织中相同通知 id 串读。
- 当前没有真实组织创建、加入或退出流程；`创建组织`、`加入组织`、`邀请成员` 和 `退出组织` 都只是 demo 确认 seam，不会申请云端空间、触发计费、校验真实邀请码、发送邮件、生成真实邀请码、写入或移除真实成员关系，也不会写入后端。
- `个人中心` 当前只在本机演示画像配置、阅读计数、学术人格、学术档案和清空确认，不会真实采样微信/飞书/本机文件，也不会删除云端或本机真实用户数据。
- `设置` 当前包含模型接入策略和文献元数据同步原型，但还不是完整设置中心。

## 3. 权限与治理边界

- `/v1/org/summary` 目前只读取 `sessionId`，没有正式鉴权、组织权限校验或管理员授权。
- 共享文献库可以切换为当前 demo 工作区，并可通过 `返回本地文献库` 恢复 starter 本地文献；但还不能浏览真实云端目录、上传、删除或同步版本。
- 配额信息只是展示，不会限制上传、解析或模型调用。
- 审计事件只是固定示例，不是由真实行为日志生成。
- 任务数量和治理摘要只是治理可视化 seam，不是实际 BullMQ、管理员后台或风控系统统计。

## 4. 后续进入生产化前需要补齐

- 真实组织 membership 模型、邀请生命周期与权限校验。
- 组织共享文献库的云端元数据、对象存储和版本控制。
- 组织通知的事件来源、云端持久化、跨设备同步、用户级已读同步和真实未读计数。
- 管理后台的组织、用户、套餐、模型任务和风控审计视图。
- 更多高风险组织 action 的二次确认；当前只注册了打开共享文献库这个低风险 action。
