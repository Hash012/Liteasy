# LiteasyClaw Phase 1 测试指南

这份文档面向没有软件开发基础的测试成员，目标是让你可以按步骤检查当前 `desktop` 原型是否达到 Phase 1 的基础可体验状态。

## 1. 本阶段测试目标

当前这一阶段，不要求产品已经完整，但应该能让你看到这些核心方向：

- 三栏桌面工作台已经存在
- 左栏可以看到文献库，导入/解析状态附着在文献条目后
- 中栏可以看到多模态产物区和固定模态按钮
- 右栏可以看到 AI 助手、模式切换、消息历史、命令反馈
- 顶部可以看到开发云账号连接状态
- 基础命令和基础问答/解释分支已经可见

说明：
当前产品定义中，中栏模态按钮是分析主干入口，右栏自然语言是导入后的分支能力。也就是说，主干应优先从左栏选中文献集与导入，再在中栏选择模态启动分析；右栏更多用于导入后的问答、解释、补充产物与设置控制。

## 2. 测试前准备

请先确认电脑上已经具备：

- `Node.js`
- `npm`
- `Rust`
- Tauri 依赖

如果你不确定，请先看：

- [environment-startup-guide.md](/home/octopus/Liteasy/docs/qa/environment-startup-guide.md)

## 3. 启动步骤

在终端执行：

```bash
cd /home/octopus/Liteasy/desktop
source "$HOME/.cargo/env"
npm install
npm run tauri dev
```

如果桌面窗口无法弹出，你也可以先用浏览器查看：

```bash
cd /home/octopus/Liteasy/desktop
npm install
npm run dev
```

然后打开终端输出的本地地址。

## 4. 测试步骤

### 步骤 1：检查整体布局

启动后先看是否有：

- 顶部品牌区和 Logo
- 顶部右侧 `云账号` 卡片
- 左栏 `Library`
- 中栏 `Reader`
- 右栏 `Assistant`

通过标准：

- 不需要上下滚动整个页面
- 整体能在窗口内完整看到

### 步骤 1.5：检查开发云账号卡片

查看顶部右侧是否能看到：

- `云账号`
- `连接开发云账号` 按钮
- 未连接时的说明文字

点击 `连接开发云账号` 后，界面应显示：

- `LiteasyClaw Researcher`
- `researcher@liteasy.dev`
- 会话有效期

关闭窗口后重新启动桌面端，顶部仍应恢复同一个账号会话。

通过标准：

- 账号可以成功连接
- 重启页面后能恢复本地保存的会话
- 不需要重新输入账号信息

### 步骤 2：检查左栏文献区

查看左栏是否能看到：

- `交给AI流程` 按钮
- `锁定选择` 按钮
- 示例论文列表
- `收藏`
- `关联推荐`

通过标准：

- 左栏不是空白
- 每个分区都能看见标题

### 步骤 3：点击交给AI流程

先在左栏勾选 1 篇或多篇论文，再点击 `交给AI流程` 按钮，观察左栏文献列表中的状态变化。

你应能看到任务状态依次出现：

- `queued`
- `parsing`
- `parsed`

通过标准：

- 状态变化是可见的，并显示在对应文献条目后
- 不需要刷新页面

### 步骤 3.5：检查关联推荐

先确保顶部已连接开发云账号，然后在左栏勾选 1 篇论文，观察 `关联推荐` 区域。

如果你勾选的是 `BERT: Pre-training of Deep Bidirectional Transformers`，当前应能看到类似：

- `RoBERTa: A Robustly Optimized BERT Pretraining Approach`
- `Semantic Scholar`
- `关联：BERT: Pre-training of Deep Bidirectional Transformers`
- `高关联`
- 推荐理由文字

通过标准：

- 推荐会随着当前选中文献集变化而更新
- 推荐条目会明确标出它与哪篇已选文献相关
- 推荐条目会显示基础关联强弱标签
- 未连接账号时，这里会明确提示先连接开发云账号
- 关闭 `联网推荐` 后，这里会明确提示推荐已关闭

你也可以在右栏 `命令` 模式输入：

```text
按检索时间排序推荐
```

或者：

```text
按关联度排序推荐
```

通过标准：

- 右栏会记录命令反馈
- 左栏推荐顺序会根据命令发生变化

### 步骤 3.8：检查收藏

在 `关联推荐` 区域出现推荐后，把其中一条推荐拖到 `收藏` 区域。

通过标准：

- `收藏` 区域会出现被拖入的条目
- 该条目会显示来源信息
- 重新打开桌面端后，收藏条目仍能恢复

### 步骤 4：检查中栏产物区

启动后先查看中栏是否能看到：

- `多模态产物`
- `树形展开`
- `思维导图`
- `PPT`
- 产物展示区域

通过标准：

- 中栏不是纯占位空白
- 已经能表现出“中栏承接主干分析结果”的方向
- 在没有形成可用选中文献集前，按钮应处于不可直接启动或提示前置条件的状态

### 步骤 5：检查右栏模式切换

查看右栏顶部是否能看到：

- `名词解释`
- `命令`
- `问答`

点击不同模式按钮，确认高亮会变化。

通过标准：

- 至少能看见模式切换
- 当前模式文字会变化

### 步骤 6：测试主干分析按钮

在左栏完成以下操作：

1. 勾选 1 篇论文
2. 点击 `锁定选择`
3. 点击中栏 `思维导图`

通过标准：

- 如果该论文尚未导入，系统应先提示或执行导入
- 导入完成后，中栏会出现新的产物卡片，例如 `Transformer Mind Map`
- 中栏状态提示会明确说明“先导入再分析”或“已启动分析”

### 步骤 7：测试问答与解释分支前置条件

先不要导入文献，直接切到右栏 `问答` 或 `名词解释` 模式，输入任意一句问题并点击 `发送`。

通过标准：

- 右栏消息历史中会记录你的输入
- 助手会明确提示你先形成并导入可用的选中文献集

然后回到左栏完成：

1. 勾选论文
2. 锁定选择
3. 点击 `交给AI流程`
4. 等待文献条目状态变成 `parsed`

再回到右栏 `问答` 或 `名词解释` 模式，重新发送问题。

通过标准：

- 右栏会出现助手回复，而不是只在顶部有静态说明
- 回复中能看到回答正文
- 回复中能看到 `引用` / `原文定位` / `可信度`

### 步骤 8：测试命令反馈与自然语言分支

在右栏输入框里输入：

```text
关闭联网推荐
```

然后点击 `发送`。

通过标准：

- 消息历史中出现你的命令
- 消息历史中出现类似“已更新 联网推荐：false”的助手回复

你也可以再试：

```text
开启用户画像
```

然后再试：

```text
请根据当前选中文献集生成思维导图
```

通过标准：

- 右栏反馈提到已根据当前选中文献集触发分支 skill
- 中栏出现 `Transformer Mind Map` 卡片或同类产物标签页

### 步骤 9：检查窗口适配

适当缩放窗口，确认：

- 页面不会整体撑爆
- 需要滚动时优先在栏内部滚动
- 不应该默认要求上下滚整页

## 5. 当前阶段通过标准

如果下面这些都成立，就可以认为当前 Phase 1 原型基本可体验：

- 桌面端能启动
- 三栏布局清晰
- Logo 和品牌区已接入
- `交给AI流程` 按钮能触发可见状态变化
- 连接云账号后，左栏能展示与当前选中文献集相关的推荐
- 推荐可以拖入左栏 `收藏` 并在重新打开后恢复
- 中栏模态按钮能承接主干分析启动
- 右栏在满足前置条件后能给出带引用和可信度的回复
- 命令模式能给出基础反馈并写入消息历史

## 6. 当前阶段已知限制

当前原型还不是完整产品，以下情况属于已知限制：

- 文献导入还是 mock 流程，不是真实 PDF 解析
- 关联推荐还是开发演示数据，不是真实在线推荐结果
- 收藏当前只做了本地持久化，不参与云端同步
- 中栏思维导图还是静态示意，不是真正生成结果
- 右栏回答是 mock retrieval，不是真实检索链
- 技能路由目前还是规则式原型，不是真实 LLM 驱动的 skill registry

## 7. 开发云联调测试

如果你要检查“桌面端是否已经能通过真实 `http` 后端联调”，请按下面步骤做。

### 步骤 1：启动开发云服务

在仓库根目录执行：

```bash
node /home/octopus/Liteasy/services/dev-cloud/server.mjs
```

看到类似下面这行就表示启动成功：

```text
LiteasyClaw dev cloud listening on http://127.0.0.1:8787
```

### 步骤 2：启动桌面端

另开一个终端，执行：

```bash
cd /home/octopus/Liteasy/desktop
source "$HOME/.cargo/env"
npm install
npm run tauri dev
```

### 步骤 3：连接开发云账号

桌面端打开后，先点击顶部右侧 `连接开发云账号`。

通过标准：

- 顶部账号卡片从“未连接”切换为已连接状态
- 显示 `LiteasyClaw Researcher`
- 显示 `researcher@liteasy.dev`

### 步骤 4：把桌面端切到开发云

打开右栏 `命令` 模式，依次发送：

```text
设置云代理端点为 http://127.0.0.1:8787
```

```text
设置云端控制平面端点为 http://127.0.0.1:8787
```

```text
同步云端策略
```

通过标准：

- 命令区会显示“已更新 云代理模型端点...”
- 命令区会显示“已更新 云端控制平面端点...”
- 策略卡片会显示 `同步状态：已同步`
- 策略卡片会显示 `策略版本：dev-policy-v1`
- 策略卡片会显示 `最近同步：2026-05-14T09:30:00Z`

### 步骤 4：验证回答已经走真实 http 链路

继续完成：

1. 左栏勾选一篇论文
2. 点击 `锁定选择`
3. 点击 `交给AI流程`
4. 等待文献条目状态变成 `parsed`
5. 切到右栏 `问答`
6. 输入任意问题并点击 `发送`

通过标准：

- 右栏出现新的助手回复
- 回复正文以 `开发云回答：` 开头，或者直接出现真实模型回答
- 助手回复下方会出现 `模型链路：...`
- 左边栏 `设置` 页面模型策略卡片中会出现 `最近执行：...`

这说明当前回答已经不再来自桌面端内置 `mock://` provider，而是通过本地开发云服务返回。
