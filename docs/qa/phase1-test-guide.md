# Liteasy Phase 1 测试指南

这份文档面向没有软件开发经验的成员，让你可以独立检查 Phase 1 的功能是否可用。

## 1. 本阶段测试目标

确认以下主链路可以完整走通：

- 导入文献
- 勾选并锁定文献
- 在三种模式下与 AI 助手对话
- 看到带原文引用和可信度的回答
- 用自然语言命令修改设置
- 生成思维导图并在中栏查看

## 2. 测试前准备

- 已安装并配置好的 Liteasy 桌面应用（参考 `docs/qa/environment-startup-guide.md`）
- 如果使用测试账号，请提前准备好

## 3. 测试步骤

### 步骤 1：启动桌面客户端

在终端进入 `desktop` 目录，执行：

```bash
npm run tauri dev
```

预期：弹出一个桌面窗口，显示 Liteasy 界面。

如果只测试前端功能，可以执行：

```bash
npm run dev
```

然后在浏览器打开 `http://127.0.0.1:1420/`。

**通过标准：** 看到顶部 LiteasyClaw 品牌区，左中右三栏分别标注为 Library、Reader、Assistant。

### 步骤 2：导入文献

1. 点击左栏"导入文献"按钮
2. 等待约 1-2 秒

**预期：**
- 左栏"导入状态"区域出现一个标记为 `[parsing]` 然后变为 `[parsed]` 的任务
- "我的文献库"中出现一篇新论文

**通过标准：** 论文条目出现在文献库列表中。

### 步骤 3：勾选并锁定文献

1. 在左栏论文列表中，勾选其中几篇论文的复选框
2. 点击"锁定选择"按钮

**预期：**
- 按钮文字变为"已锁定"
- 复选框变为不可修改状态

**通过标准：** 锁定后无法更改勾选。

### 步骤 4：在"名词解释"模式提问

1. 点击右栏顶部"名词解释"按钮
2. 在输入框输入"什么是attention"或"解释attention"
3. 按 Enter 或点击"发送"

**预期：**
- 右栏消息区出现你的问题
- AI 返回一段包含引用定位（如 `[1] p.2 — ...`）和可信度百分比（如 `可信度：87%（高可信）`）的回答

**通过标准：** 回答中包含原文引用和可信度信息。

### 步骤 5：在"问答"模式提问

1. 点击右栏顶部"问答"按钮
2. 输入"BERT的预训练任务是什么"或"解释Transformer"
3. 发送

**预期：** AI 返回一篇关于 BERT 或 Transformer 的详细回答，包含引用和可信度。

**通过标准：** 回答内容与问题相关，且包含引用定位。

### 步骤 6：在"命令"模式修改设置

1. 点击右栏顶部"命令"按钮
2. 依次输入并发送以下命令：
   - "关闭联网推荐"
   - "开启用户画像"
   - "使用英文"
3. 再输入一个无法识别的命令，如"帮我写论文"

**预期：**
- "关闭联网推荐" → AI 回复"已执行：联网推荐 → 关闭"
- "开启用户画像" → AI 回复"已执行：用户画像 → 开启"
- "使用英文" → AI 回复"已执行：助手语言 → en"
- "帮我写论文" → AI 回复"无法识别指令"，并给出可用的命令提示

**通过标准：** 已知命令正确执行并反馈结果；未知命令给出可理解的错误提示。

### 步骤 7：生成思维导图

1. 保持在"命令"模式
2. 输入"生成思维导图"
3. 发送

**预期：**
- 右栏 AI 回复"正在生成思维导图，请查看中栏..."
- 约 2 秒后，中栏出现一个新的标签页，标题为"思维导图"
- 标签页内容显示树形结构的思维导图（包含研究背景、核心方法、实验设计、结论与展望等节点）

**通过标准：** 中栏出现思维导图标签页，内容结构清晰可读。

### 步骤 8：手动测试清单

逐条检查以下项目：

- [ ] 桌面端能启动
- [ ] 三栏结构可见
- [ ] 能导入论文
- [ ] 能勾选并锁定论文
- [ ] "名词解释"模式能返回解释
- [ ] "问答"模式能返回回答
- [ ] 回答中包含原文引用定位
- [ ] 回答中包含可信度信息
- [ ] "命令"模式能修改设置
- [ ] 未知命令给出可理解的错误提示
- [ ] 能生成思维导图并在中栏查看

## 4. 常见异常

| 现象 | 可能原因 | 先检查 |
|---|---|---|
| 窗口没弹出来 | Tauri 依赖未安装 | 终端是否有红色报错 |
| 发送消息无反应 | 前端与 Store 连接异常 | 打开浏览器开发者工具看 Console 错误 |
| 回答没有引用 | 问题关键词未命中 mock 数据 | 试试包含 attention、BERT、Transformer 等关键词的问题 |
| 中栏没有思维导图 | 异步任务未完成 | 等待 3 秒后检查中栏 |

## 5. 是否通过的判断标准

- 从导入到生成思维导图，**能否在 10 分钟内完整走完**
- AI 回答是否包含**引用定位**和**可信度**
- 命令式设置控制是否**稳定执行**
- 思维导图是否**可查看**
