# Liteasy 路演部署与演示指南

这份文档面向需要把 Liteasy 部署到云端并进行路演展示的成员。

目标不是讲完整研发细节，而是帮助你用一套尽量稳定、可重复的方式完成：

- 启动服务
- 检查服务
- 连接桌面端
- 按既定顺序演示核心流程

## 1. 本次路演到底部署什么

当前路演版本由三部分组成：

1. `desktop` 客户用户端
2. `services/dev-cloud/server.mjs` 提供的云端 demo 服务
3. `/admin/` 提供的内部运营与运维后台 demo

请注意：

- 客户组织侧管理仍然在用户软件里演示
- `/admin/` 只用于展示 Liteasy 平台内部运维/运营视角
- 当前不是完整生产 SaaS，只是可部署、可演示的路演版本

## 2. 什么部署到云端，什么保留本地

建议路演时采用以下形态：

- 云端部署：
  - `services/dev-cloud/server.mjs`
  - 路演所需环境变量
- 本地运行：
  - `desktop` 桌面端

这样做的好处是：

- 云端地址可用于展示“服务器部署端”
- 桌面端仍保留当前最稳定的用户交互体验

## 3. 需要准备的环境变量

最少需要确认这些环境变量：

```bash
LITEASY_DEV_CLOUD_HOST=0.0.0.0
LITEASY_DEV_CLOUD_PORT=8787
LITEASY_DEV_CLOUD_PUBLIC_ORIGIN=https://你的演示域名
```

如果桌面演示页、内部说明或后台卡片需要展示桌面入口，也可以配置：

```bash
LITEASY_DESKTOP_PUBLIC_ORIGIN=http://127.0.0.1:1420
```

如果你希望模型生成调用真实 OpenAI，而不是演示回答，再额外配置：

```bash
OPENAI_API_KEY=你的密钥
OPENAI_BASE_URL=https://api.openai.com/v1
```

## 4. 云端启动顺序

在服务器上进入仓库根目录后执行：

```bash
node services/dev-cloud/server.mjs
```

如果环境变量已经设置好，服务会按设定 host 和 port 监听。

如果要在路演前恢复一个稳定起点，建议先执行：

```bash
node scripts/reset-demo-data.mjs
node scripts/reseed-demo-data.mjs
```

启动成功后，再执行：

```bash
node scripts/smoke-roadshow.mjs http://127.0.0.1:8787
```

这会统一检查根索引、健康检查、运维端页面和 demo-state 接口。

## 5. 启动后先做哪些 smoke check

路演前至少检查这几项：

1. 服务根索引可访问
2. `/healthz` 可访问
3. `/admin/` 可访问
4. `/v1/admin/demo-state` 可访问
5. 桌面端可以连接云账号
6. 组织页可以加载
7. 推荐流程可见
8. 助手问答可返回结果

建议检查地址：

- `https://你的演示域名/`
- `https://你的演示域名/healthz`
- `https://你的演示域名/admin/`
- `https://你的演示域名/v1/admin/demo-state`

## 6. 桌面端如何连接部署后的云端

桌面端不再向普通用户暴露“开发云”“端点切换”“控制平面端点”这些调试概念。

路演前应直接把桌面端构建或运行环境配置到你的演示云端地址。用户进入软件后：

- 默认处于未登录状态
- 点击 `登录云账号`
- 完成 Demo 登录
- 打开 `组织`
- 验证组织空间和推荐链路

## 7. 推荐的路演顺序

建议按这个顺序演示：

1. 打开桌面端，展示三栏主界面
2. 登录云账号
3. 进入组织页，展示组织空间和共享文献库入口
4. 返回文献库，展示选中文献集和导入/分析主干
5. 展示右栏助手问答
6. 展示左栏推荐
7. 展示中栏产物
8. 最后打开 `/admin/`，说明这是 Liteasy 平台内部运营/运维视角

进入 `/admin/` 后，建议重点展示：

- 活跃会话数
- 收藏总数
- 推荐缓存条目数
- 客户组织资源表
- 最近活动
- `重置 Demo 数据` 与 `重新播种 Demo 数据` 按钮

## 8. 出现问题时的 fallback 动作

如果现场环境不稳定，优先使用以下 fallback：

- 推荐异常：切换到已准备好的已登录会话和已有推荐结果
- OpenAI 不稳定：回退到开发云演示回答
- 组织接口异常：优先展示本地主工作台与助手主链路
- `/admin/` 加载慢：直接用根索引和已准备好的页面截图说明边界
- demo 状态脏了：直接执行 reset + reseed，再刷新 `/admin/`

## 9. 当前不建议重点演示的内容

如果不是本次路演主叙事，以下内容建议避免临场深挖：

- 真实生产化账号体系
- 真实多租户权限校验
- 收藏与缓存的完整正式数据生命周期
- 插件生态
- 复杂长任务生成
- 任何需要解释“这目前还是 demo 数据”的高风险深链路

## 10. 路演前最后检查清单

- 云端服务根索引正常
- `/healthz` 正常
- `/admin/` 正常
- `/v1/admin/demo-state` 正常
- 桌面端能连接云账号
- 组织页正常
- 推荐可见
- 助手可答复
- 至少一个中栏产物可以展示
- 已准备一套备用讲解路径
