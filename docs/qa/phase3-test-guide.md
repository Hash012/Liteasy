# Liteasy Phase 3 组织空间测试指南

这份文档面向没有软件开发经验的成员，用来检查 Phase 3 第一段“组织空间、个人中心、设置左边栏”是否能在桌面端看到。

## 1. 测试前先确认

Phase 3 当前仍是原型切片，不是正式组织协作后台。它主要验证产品方案原文中的这些入口：

- `左边栏` 是最左侧窄竖栏，类似 VSCode Activity Bar，包含 `文献库 / 组织 / 个人中心 / 设置`
- `左栏` 是窄竖栏右侧的内容区域，会在文献库、组织、个人中心、设置之间切换
- `右栏` 只保留极简 AI 助手对话框，不再承载组织空间、组织治理、模型接入策略或文献元数据同步卡片
- 用户可以看到自己加入的组织、组织成员、通知、共享文献库、配额、任务和审计摘要

完整边界请先看：

```text
/home/octopus/Liteasy/docs/qa/phase3-governance-limitations.md
```

## 2. 启动开发云服务

打开第一个终端，在仓库根目录执行：

```bash
cd /home/octopus/Liteasy
node /home/octopus/Liteasy/services/dev-cloud/server.mjs
```

看到下面这行表示成功：

```text
Liteasy dev cloud listening on http://127.0.0.1:8787
```

浏览器直接打开 `http://127.0.0.1:8787/` 时应看到开发云服务索引 JSON，而不是空白页或 `not_found`。这个地址只是开发云 API 服务，不是桌面端页面。

## 3. 启动桌面端

打开第二个终端执行：

```bash
cd /home/octopus/Liteasy/desktop
source "$HOME/.cargo/env"
npm run tauri dev
```

如果桌面窗口打不开，也可以先执行：

```bash
npm run dev
```

然后打开终端里显示的本地地址，一般是：

```text
http://127.0.0.1:1420/
```

## 4. 检查基础布局

启动后应能看到：

- 顶部品牌区带有微型模型指示，例如 `模型：云代理`
- 最左侧窄竖栏显示 `文献库 / 组织 / 个人中心 / 设置`
- 左栏默认是 `Library`，展示 `我的文献库`
- 中栏是 `Reader`
- 右栏是 `AI Assistant`，只包含模式切换、对话记录、输入框和发送按钮

右栏不应出现 `模型接入策略`、`文献元数据同步`、`组织空间` 或 `组织治理` 卡片。

## 5. 连接开发云账号

在 Liteasy 窗口顶部找到 `云账号` 卡片，点击：

```text
连接开发云账号
```

正常结果：

- 顶部显示 `Liteasy Researcher`
- 邮箱显示 `researcher@liteasy.dev`
- 账号状态提示会话已经保存在本地

## 6. 检查设置页

在最左侧窄竖栏点击：

```text
设置
```

左栏会切换为 `Settings`。你应该能看到：

- `模型接入策略`
- `同步云端策略`
- `文献元数据同步`
- `当前通道：云代理` 或 `当前通道：本地直连`
- `同步状态：已同步`

模型接入策略的详细切换和同步状态都在设置页；主页顶部只保留微型模型状态指示。

## 7. 检查组织页

在最左侧窄竖栏点击：

```text
组织
```

左栏会切换为 `Organization`。连接账号后应该能看到：

- `组织空间：Liteasy AI Reading Lab`
- `已加入组织：Liteasy AI Reading Lab、Liteasy Literature Ops`
- `角色：研究员 · 成员 12 人`
- `组织成员：Liteasy Researcher（研究员）、Admin（管理员）`
- `共享文献库：组织共享文献库 · 48 篇`
- `通知：公告 · 管理员发布了本周阅读主题。`
- `通知：文献上传 · 成员上传了 Graph Neural Networks 综述。`
- `通知：文献库变更 · 共享文献库结构新增 RAG 目录。`
- `未读通知：3 条`

点击 `全部标记已读` 后，未读计数变为 `未读通知：0 条`，中栏提示显示 `组织通知已全部标记为已读。`。刷新或重新打开前端后，本机浏览器会从 localStorage 恢复已读状态；切换到其他组织时，通知已读状态按组织隔离，不会因为通知 id 相同而串读；点击 `断开云账号` 会清理本机通知已读状态。

组织页还包含 `打开组织窗口`，用于查看更完整的组织列表和详情。

点击 `创建组织` 会出现 `创建组织` 弹窗，默认组织名称为 `Liteasy Demo Organization`。当前为 demo seam：点击 `创建 demo 组织申请` 只会在中栏提示 `已创建 Liteasy Demo Organization 的 demo 组织申请，等待正式后端接入。`，不会写入真实组织列表、申请云端空间或触发计费；点击 `取消` 或 `关闭` 不会创建提示。

点击 `加入组织` 会出现 `加入组织` 弹窗，默认邀请码为 `LITEASY-DEMO-JOIN`。当前为 demo seam：点击 `提交 demo 加入申请` 只会在中栏提示 `已提交组织邀请码 LITEASY-DEMO-JOIN 的 demo 加入申请，等待正式后端接入。`，不会校验真实邀请码、写入成员关系或触发管理员审批；点击 `取消` 或 `关闭` 不会创建提示。

点击 `邀请成员` 会出现 `邀请成员确认` 弹窗。当前为 demo seam：点击 `发送 demo 邀请` 只会在中栏提示 `已创建 Liteasy AI Reading Lab 的 demo 邀请，等待正式后端接入。`，不会发送真实邮件；点击 `取消` 或 `关闭` 不会创建提示。

点击 `退出组织` 会出现 `退出组织确认` 弹窗。当前为 demo seam：点击 `创建 demo 退出请求` 只会在中栏提示 `已创建退出 Liteasy AI Reading Lab 的 demo 请求，等待正式后端接入。`，不会移除组织列表、成员关系或共享文献库访问；点击 `取消` 或 `关闭` 不会创建提示。

## 8. 切换已加入组织

在组织页中点击：

```text
查看 Liteasy Literature Ops
```

正常结果：

- 组织空间标题变为 `组织空间：Liteasy Literature Ops`
- 角色摘要变为 `角色：管理员 · 成员 4 人`
- 共享文献库摘要变为 `共享文献库：文献运营共享库 · 16 篇`
- 组织治理摘要变为 `治理后台：待复核 1 项，高风险 0 项`

当前只是两个固定 demo 组织之间切换，不代表已经支持真实组织加入、创建或退出。

## 9. 检查组织治理

在组织页查找 `组织治理` 卡片。你应该能看到：

- `治理后台：待复核 3 项，高风险 1 项`
- `组织配额：存储 38 / 100 GB，模型调用 4200 / 10000`
- `后台任务：组织共享文献库索引刷新（running）`
- `审计队列：Admin 更新共享文献库上传权限（medium）`

这些内容只是治理可视化入口，不代表已经有正式管理员后台。

## 10. 打开组织窗口

在组织页点击：

```text
打开组织窗口
```

正常结果：

- 页面中央出现 `组织窗口`
- 左侧显示组织列表
- 右侧显示选中组织的成员、通知和共享文献库详情
- 可以点击 `打开 Liteasy Literature Ops 详情` 查看第二个 demo 组织

## 11. 打开组织共享文献库

在组织页点击：

```text
打开共享文献库
```

正常结果：

- 左栏自动切回 `文献库`
- 左栏显示 `当前工作区：组织共享文献库（Liteasy AI Reading Lab）`
- 左栏 `我的文献库` 中出现 `Organization Reading List: Retrieval-Augmented Generation`
- 左栏 `我的文献库` 中出现 `Team Notes on Long-Context Evaluation`
- 本地 starter 文献不再显示在当前工作区中
- 中栏提示更新为 `已打开组织共享文献库：组织共享文献库。`

这一步的行为类似 VSCode 打开一个新的文件夹：切换当前工作区，而不是把组织文献和本地文献取并集。连接开发云账号和切换到组织页只加载组织信息，不会自动打开共享文献库。

如果需要回到本地 demo 文献，在左栏点击：

```text
返回本地文献库
```

正常结果：

- 左栏显示 `当前工作区：本地文献库`
- `Attention Is All You Need` 和 `BERT: Pre-training of Deep Bidirectional Transformers` 重新出现
- 组织共享文献不再显示在当前工作区中
- 中栏提示更新为 `已返回本地文献库。`

也可以在右栏命令模式输入：

```text
打开组织共享文献库
```

正常结果与点击按钮相同。这个命令已经走注册 skill/action 边界，不是把自然语言直接映射成本地任意操作。

当前这一步只切换开发云返回的 demo 组织文献工作区，不代表已经支持真实云端目录浏览、上传或删除。

## 12. 打开个人中心

在最左侧窄竖栏点击：

```text
个人中心
```

正常结果：

- 左栏文献库区域切换为 `个人中心`
- 显示 `昵称：Liteasy Researcher`
- 显示 `用户 ID：demo-session-1`
- 显示 `所在团队：Liteasy AI Reading Lab`
- 显示 `画像配置：性别 未设置 · 年龄 未设置 · 学段 未设置`
- 显示 `用户画像：已关闭`

点击：

```text
开启用户画像
```

正常结果：

- 显示 `用户画像：已开启`
- 显示 `已阅读论文数：2`
- 显示 `学术人格：跨学科综述型`
- 显示 `学术档案` 和 `清空用户画像（需鉴权）` 按钮

继续点击 `学术档案` 应出现 `学术档案页面`；点击 `清空用户画像（需鉴权）` 后应出现 `清空用户画像确认`。

## 13. 当前不能验收什么

不要把下面能力当作已经完成：

- 真实组织创建、邀请、加入、退出
- 真实组织权限、管理员审批和风控策略
- 真实云端共享文献库目录浏览、上传、删除和版本管理
- 真实微信、飞书、本地文件授权采样
- 真实清空云端或本地用户画像数据
