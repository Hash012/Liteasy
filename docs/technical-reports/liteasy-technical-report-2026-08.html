摘要

科研阅读的困难并不只在“读懂一篇论文”，而在于把分散的文件、来源证据、解释过程、跨文献关系、个体认知和协作讨论组织成一个可持续的工作系统。Liteasy 以桌面端为主要入口，围绕“建立工作区、锁定文献、导入解析、证据检索、渐进式薄读、生成学习产物、沉淀知识与社区协作”构建闭环。系统采用 Tauri + React + TypeScript 的桌面工作台、Rust 本地能力层、Node.js 云服务、PostgreSQL、S3 API 对象存储、Keycloak 统一身份和受控模型网关，并以 IntuEcho 承担学术内容协作与文献身份权威。

技术设计的核心不是把大模型直接接入界面，而是建立三条可验证边界：其一，模型只能通过已注册的技能与动作修改系统状态；其二，论文解释必须按来源模式组织证据，并对句子、数值和图表关系逐级校验；其三，本地文件、个人云端数据、组织共享数据、平台配置与临时缓存拥有不同真源、权限和生命周期。本文给出问题分析、技术路线、系统上下文、模块与数据设计、关键流程、安全可靠性、部署与测试体系，并在附录中集中说明能力边界及后续完善项。

关键词：科研阅读；检索增强生成；证据可追溯；智能代理；生成式界面；本地优先；文献身份；多模态可视化

CHAPTER 01

问题分析

Liteasy 面向的不是一次性的“论文问答”，而是科研用户长期处理文献、证据、理解、产物和协作关系时形成的系统性摩擦。

1.1 科研阅读的系统性矛盾

资料存在于文件，理解存在于上下文

PDF、收藏、推荐和组织资料分散在不同位置。用户真正关心的是“当前工作区、当前选中文献、当前问题和已有认知”组成的上下文，而不是单个文件本身。

生成速度快，证据核验慢

大模型可以快速生成流畅解释，但论文结论、实验数字和图表关系必须回到可定位来源；否则“读起来像对的”无法转化为可引用的科研知识。

自然语言灵活，软件状态要求确定

“帮我整理工作区”可能涉及移动、覆盖、上传或删除。自然语言具有歧义，而软件状态变更需要权限、参数、确认、幂等和恢复机制。

个性化有价值，数据边界必须清晰

解释深度、领域偏好和阅读轨迹能提升体验，但本地绝对路径、原文、批注和组织资料不应被无差别收集或跨作用域混用。

单篇阅读容易，跨版本协作困难

DOI、预印本、会议版、期刊版、文件副本和内容哈希代表不同身份。错误合并会把用户私有批注、社区内容与学术版本混为一谈。

多模态直观，但任意渲染不可控

图、表、公式、动画和三维表达能降低认知负担，却同时引入脚本安全、布局稳定、语义正确、设备性能和降级路径等工程问题。

输入分散本地 PDF、收藏、推荐、组织资料
→
上下文不稳文件选择、导入状态和问题范围易错位
→
生成不可证解释、数字和图表缺少来源绑定
→
知识难沉淀结果无法复用、比较、协作和追踪
系统解法用“受控上下文 + 可追溯证据 + 类型化产物 + 分域存储”把阅读过程变成可审计、可恢复、可复用的知识生产链。

CHAPTER 02

产品闭环与设计思想

产品主线从“打开文件”升级为“建立可追溯认知资产”。每个环节都保留显式状态，使用户知道系统掌握了什么、正在做什么、结果从哪里来。

2.1 从文件到认知资产

建立工作区打开本地库或组织共享资料区
→
勾选并锁定形成稳定的选中文献集快照
→
导入与解析校验、提取、切块、索引、引用定位
→
薄读与问答按证据模式解释并逐层展开
→
生成产物认知图、导图、表格、可视化
→
沉淀与协作版本、记忆、批注、社区与画像
图 2　Liteasy 核心用户闭环

工作区是“当前可见的目录视图”，选中文献集是“用户勾选并锁定、准备交给智能能力处理的文件快照”。二者刻意分离：目录可以继续变化，而一次分析必须基于稳定输入。导入不是简单上传，而是对文献执行安全校验、文本与结构提取、切块、索引和定位准备。分析结果以产物及版本保存，能够被再次打开、继续下钻或与社区内容关联。

2.2 五项架构原则

证据优先

论文事实、外部知识、社区表达、用户笔记与 AI 独立理解分别标注，不能用流畅措辞掩盖来源差异。

动作受控

按钮、自然语言和快捷入口复用同一动作注册表；权限、风险和确认在执行前统一处理。

本地优先

本地文件与私有阅读细节以设备为权威；云端承担协作、同步、推荐、任务与治理。

协议驱动

模型输出进入类型化协议和校验管线，界面不执行任意模型代码，数据也不依赖自由文本猜测。

失败可恢复

长任务有状态，写入具备幂等键和版本检查，文件操作使用原子提交或可恢复事务。

渐进展开

先呈现少量核心节点，再随用户兴趣加载细节，以认知负担和证据密度共同决定深度。

一句话架构思想大模型负责提出解释和计划，确定性系统负责决定“能不能做、依据是否成立、结果能否保存”。

CHAPTER 05

智能代理与安全执行

Liteasy 的智能代理是工作台的统一交互入口，但不是绕过应用规则的超级权限。它把自然语言目标转换为可校验计划，再通过受控动作执行。

5.1 受控动作链

1. 准备本轮上下文读取当前工作区、锁定文献集、导入状态、组织作用域、用户设置、预算和可用能力。
2. 识别目标并形成结构化计划模型或确定性路由只提出意图、参数和动作序列，不直接触碰应用状态。
3. 校验计划与资源作用域检查动作是否注册、参数是否符合契约、文献是否已锁定/导入、目标资源是否属于当前作用域。
4. 策略裁决与用户确认低风险视图操作可即时执行；删除、覆盖、上传、组织写入、画像采样和付费资源必须确认。
5. 执行动作并发布事件按钮、命令和快捷入口复用同一动作实现，长任务产生排队、运行、进度、成功或失败事件。
6. 观察结果并呈现恢复路径记录执行结果、预算与失败原因；界面显示产物、审计信息或可执行的下一步。
图 7　一次智能操作的动态流程

5.2 技能、动作与插件边界

技能描述“如何完成一类任务”，可以组合检索、生成和动作；动作描述“系统允许改变的一个确定状态”，具有类型化参数、风险、作用域和执行器。插件只能通过公开能力注册点扩展技能、界面项或受控动作，不能获得任意 DOM、文件系统或服务凭据访问。由此形成一条清晰的权限路径：

用户目标 → 技能选择 → 动作计划 → 契约校验 → 策略与确认 → 确定性执行器任何模型输出在进入执行器前都不是事实，也不是授权。

5.3 生成式界面

CHAPTER 06

薄读、证据与多模态

“薄读”不是把论文压缩成更短的摘要，而是先构建低认知成本的全景，再允许用户沿概念、机制、实验或疑问逐层加深，同时持续维护来源与证明关系。

6.1 渐进认知图

认知结构采用有向多重图。只有“从略到详”的展开关系要求无环，解释、支持、反驳、先修、比较、来源和直觉关系可以交叉连接。领域事实保存在规范化认知图中，界面描述只是对图的投影；用户每次展开只提交带基础版本号的局部补丁，避免整图覆盖和并发丢失。

第 0 层：一句话全景核心结论与历史坐标
第 1 层：问题骨架问题、机制、主要结果
第 2 层：概念解释直觉、先修与关键关系
第 3 层：证据细节实验、推导、限制
第 4 层：深度拓展跨文献比较与开放问题
双深度控制系统同时考虑“内容本身的基础深度”和“当前用户需要看到的呈现深度”。点击次数只是信号，不能机械地等同于知识层级。

6.4 数值与图表保真

数值保真门

每个正文定量主张都要有合法证明路径，逐项匹配主体、指标、关系、值、单位、比较对象、限定词、不确定性与实验条件。

数值完整性门

仅在用户要求“列全结果”或任务定义必需事实集合时启用，避免把合理省略误判为错误。

图表结构门

仅在存在结构化图表证据时验证行列、图例、坐标和区域关系；数字相邻不能被推断为表格关系。

数值证明坚持原子性：默认由同一来源、同一实验范围内的事实支持一个经验主张，禁止跨论文、跨硬件、跨数据集或跨统计口径拼接新比较。失败修复遵循“确定性规范化 → 删除非正文可选字段 → 只改失败句 → 隔离不合格句 → 定向换源 → 合法切换来源模式”的顺序，已经通过的句子和来源映射保持冻结。

6.5 多模态产物

系统把多模态生成拆为“意图、证据、产物协议、编译器、渲染器、校验器”六个角色。语义图、电路与物理图、生物结构、函数与几何、过程动画、栅格插图分别使用专用编译器；界面根据设备能力和产物状态选择 SVG、Canvas、WebGL、图片或无障碍文本降级。自动视觉增强与正文拥有独立预算，因此附属图像失败不会破坏已经合格的正文。

CHAPTER 08

安全、部署与运行

安全设计贯穿身份、文件、模型、对象和界面五个面向。预发布环境采用单一 HTTPS 入口与内部网络隔离，并把数据库、对象存储和扫描服务作为就绪条件。

8.1 身份、授权与隔离

统一身份，不共享业务会话

桌面、社区和管理端使用不同 OIDC 客户端与令牌受众。管理登录具有独立认证流和多因素要求。

服务端是最终授权点

前端禁用控件只改善体验；用户作用域来自签名令牌，组织成员与存储策略由数据库重新判断。

上传链路故障关闭

PDF 限制大小和类型，经私有 HTTPS 扫描并绑定内容哈希；扫描不可用时拒绝上传。

模型密钥与路由固定

上游模型、密钥和能力由部署配置决定，桌面客户端不能覆盖；输出仍要经过协议与质量门。

路径与对象防越界

本地命令拒绝路径穿越和危险重解析点；云端下载先验证逻辑条目权限，再解析对象引用。

最小化个性化数据

允许上传必要题录和显式行为，不上传绝对路径、用户名、无关目录、私密批注或任意文件内容。

上述控制与 NIST AI 风险管理框架的“治理、映射、测量、管理”循环一致 [6]，并针对 OWASP 大模型应用风险中的提示注入、不安全输出处理、敏感信息泄露、过度代理权限和无界消耗设置确定性边界 [7]。

B.3 术语表

术语本文含义
工作区当前可见的本地或组织文献目录视图；切换工作区不是合并资源。
选中文献集用户在当前工作区勾选并锁定、准备交给智能能力处理的文件快照。
导入对选中文献执行校验、解析、切块、索引和引用定位准备。
产物具有类型、来源、版本和生命周期的分析结果，如认知图、导图、表格或可视化。
技能完成一类用户任务的受控流程，可以组合检索、生成和动作。
动作一个可以确定性执行的状态变更，带类型化参数、资源作用域、风险与权限。
证据锚点连接解释与来源的定位信息，可包含页码、文本范围、结构区、坐标或内容哈希。
薄读先建立低认知成本全景，再沿用户关注点逐层展开的证据约束阅读方式。
