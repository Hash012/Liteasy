# 非 PDF 阅读器调研与 Liteasy 落地（2026-09-27）

本轮针对论文提取图文阅读模式。Liteasy 的 EPUB / Markdown / TXT 阅读器已具备章节目录、文内搜索、主题、位置保存和章节翻页；本轮补齐论文阅读模式的对应能力，并保留现有的原文 / 译文对照和共用 PDF 批注。

## 官方资料与可借鉴功能

| 产品 | 官方资料中确认的功能 | 对论文阅读的启发 |
| --- | --- | --- |
| Readwise Reader | 快捷键；区分阅读进度和最后位置；跳转浏览后返回原阅读位置 | 搜索、查目录不应让读者丢掉阅读位置；仅凭滚动不能声称用户已读。来源：[Basics](https://docs.readwise.io/reader/docs/faqs)。 |
| KOReader | 丰富的字体与间距配置、夜间模式、书签 / 高亮 / 笔记、目录工具、全文查找、阅读统计、笔记导出、词典与翻译 | 长论文需要导航、定位与回看，而不只是放大字体。来源：[官方用户指南](https://koreader.rocks/user_guide/)。 |
| Apple Books | 字号、字体、页面主题、明暗背景、间距、对齐、多栏和全屏 | 将常用排版收进一个外观面板，并提供舒适主题和专注阅读。来源：[Change a book’s appearance](https://support.apple.com/guide/books/change-a-books-appearance-ibks8923126d/mac)。 |

## 本轮已加入

1. 六级章节目录，随滚动指示当前章节；无标题时按可用 PDF 页码导航。
2. 文内查找，带上下文的命中段落预览、上下段切换和键盘操作；不破坏公式、图片或行内格式。
3. 本机书签、重复提示、移除，按论文和账号隔离，并注明原文 / 译文。
4. 阅读位置记忆，采用段落和段内比例恢复；重排、图片加载和重开继续定位，正文改变时回退滚动比例。
5. 跳转历史，可逐次回到目录、查找、书签跳转前的位置。
6. 底栏当前位置和粗略剩余阅读时间，明确时间估算规则。
7. 四种主题、三档段间距，沿用已有字号、字体、行距、宽度和对齐设置。
8. 专注阅读，正文铺满应用窗口；退出恢复批注，临时隐藏不丢失草稿。
9. 查找、书签、专注和退出快捷键，避免与隐藏 PDF 的快捷键冲突。

导航和书签不复制正文，也不修改识别资产。批注继续由同一个 PDF 批注仓库管理。目录、查找、书签共用一个紧凑导航面板，与批注栏按需切换，避免长期堆叠更多侧栏。
