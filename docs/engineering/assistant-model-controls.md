# 对话模型与思考深度

输入框底部的思考深度默认收起为图标：快速使用闪电，均衡和熟虑使用大脑图标，悬浮提示和可访问名称显示当前档位。点击展开三档滑条，点击外部或按 Escape 收起；支持方向键、Home 和 End。深度沿用现有请求中的 `thinkingDepth` 与提供商无关的分析/核验指令，不向不支持的 API 强行附加推理参数，也不承诺固定响应时间。

模型按钮显示当前模型，点击后可以搜索、选择用户已验证的配置。同一服务商可保存多个模型，同一模型可使用不同地址。候选来源是「设置 → AI 接入 → 保存并测试」收到真实、非空响应的配置；服务商预设列表、仅填写 API key 或仅保存配置不会被当作可用性验证。历史版本没有保存测试记录的配置需重新测试一次。这里列出用户逐项验证的模型，不自动枚举服务商的模型目录或批量发送计费测试请求。

切换会同时更新接入方式、服务商、地址、模型 ID、协议和结构化输出设置，实际请求与显示保持一致，选中配置跨启动保留。当前对话有执行中或排队任务时，输入框的模型切换暂不可用。已发起请求沿用其原有执行路径。

验证记录存于 `liteasy.verified-models.v1`，只含白名单配置字段与验证时间，不含密钥。桌面凭据仍使用已有系统凭据库，浏览器预览的密钥仍仅保存在当前页面会话。候选展示和选择时都会检查密钥是否存在；无须密钥的本机 Ollama 也必须先通过测试。更换或删除某个服务商/地址的密钥会清除该凭据范围内所有模型的验证记录；重测失败则移除对应配置。浏览器刷新后无密钥的配置不再显示为可选。

回归包括 `verifiedModelProfiles.test.tsx`、`ModelConnectionPanel.test.tsx`、`AssistantComposer.test.tsx`、`assistantArtifactRouting.test.tsx`，以及 `browser/modelConnection.browser.spec.ts`。浏览器用例使用拦截的测试 API 验证切换后的实际模型、地址和凭据，不消耗真实模型额度。
