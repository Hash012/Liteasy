# 论文阅读模式与共用批注

论文解析完成后，在 PDF 工具栏切换「阅读模式」。「阅读排版」支持 14–30 px 字号、衬线 / 无衬线 / 跟随界面字体、页面宽度、行距、段间距和对齐方式，以及跟随应用 / 纸白 / 暖纸 / 夜读主题。设置按本机账号保存，修改排版不改写论文或识别内容；字号和版宽变化时按正文段落及段内比例保留位置。原文、译文和对照视图沿用同一套排版。

## 长文导航

- 目录读取当前正文的六级标题，没有标题时使用可用的原始页码；都不可用时明确提示使用查找或书签。滚动时标记当前章节。
- 文内查找不区分大小写，显示带命中词的段落预览，最多显示前 100 个匹配段落。点击或 Enter / Shift + Enter 定位下一 / 上一段，不改写正文 DOM 文本、公式、图片或原始资产。
- 书签按账号和论文保存，保留原文 / 译文范围，支持去重和移除。本机位置记录也分语言视图保存；切换论文或账号不会串用。原文、译文同时存在时只导航原文，仅看译文时导航译文。打开另一语言视图的书签会提示先切换，不错配原文位置。
- 位置保存以段落内容指纹、重复段落序号、段内比例为主，文档滚动比例为后备。图片加载、排版变化和重新打开会恢复位置；文本变化导致锚点失效时按比例定位。离开时立即保存，滚动保存有 400 ms 防抖。
- 「返回跳转前」保留最近 20 次目录、查找和书签跳转的来源位置。底栏展示当前位置百分比及粗略剩余时长，不把滚动位置当作已读或理解进度；时长按中文 300 字 / 分钟、英文 220 词 / 分钟估算，图表公式的额外时间不计入。
- 专注模式将正文铺满应用窗口，收起操作区及批注栏；退出后恢复批注和未保存的草稿。目录、查找和书签仍可使用。
- 阅读区域内 Ctrl / ⌘ + F 查找，Ctrl / ⌘ + Shift + B 收藏，Ctrl / ⌘ + Shift + F 切换专注；Esc 关闭导航或退出专注。隐藏的 PDF 不再截获查找快捷键。

## 批注一致性

PDF 与阅读模式由同一个 `PdfReader` 管理批注。阅读界面通过 `PdfReadingAnnotations` 使用其当前数据、版本检查和保存流程，不维护第二份 comments，也不在切换模式时复制批注。已有评论、图片附件和 AI review 可查看；评论可编辑和删除，已公开批注继续沿用原有的更新与撤回流程。新建阅读批注默认私有。

- 在原文选段后填写评论，或使用「添加页批注」记录整页想法。根据 PDF 正文和逐页提取内容推断页码；无法确定时由用户选择，不把译文选段冒充原文。
- 只有 PDF 字符模型中唯一匹配的选段才生成几何高亮。未加载页面、OCR 差异或重复文本保留页码与引用文字，不猜测高亮坐标。
- 点击阅读批注的引文可定位正文段落；「查看 PDF」打开原页。PDF 批注展开后的「在阅读模式查看批注」可反向定位。无法匹配时明确提示页级定位，手绘仍可回到 PDF 查看笔迹。
- 保存失败保留编辑内容；相同内容可重试，过期编辑不能覆盖较新的批注。切换论文或账号后，旧会话不能写入新范围。

实现入口：`PaperReadingWorkspace.tsx`、`PaperReadingNavigator.tsx`、`usePaperReadingNavigation.ts`、`paperReadingNavigation.ts`、`paperReadingPreferences.ts`、`pdfReadingAnnotations.ts` 和 `PdfReader.tsx`。验证包括 `PaperReadingWorkspace.test.tsx` 的共用数据、重开、排版持久化、版本冲突、范围隔离及定位边界；`PaperReadingNavigation.test.tsx` 的导航、书签隔离、语言视图、草稿保留、存储失败和位置恢复；`paperReading.browser.spec.ts` 的真实 PDF 双向批注、长文导航、位置重排恢复、主题与专注交互。
