# 书库、元信息与阅读外观

左侧活动栏的「书库与元信息」在主区域打开文件列表及详情栏，汇总当前工作区 PDF 和当前账号导入的 EPUB、Markdown、TXT。原有文献库继续管理 PDF 文件夹、组织文献和分析选中集；打开 PDF 沿用原阅读器和批注机制。

## 文件管理

- 搜索标题、作者、DOI、出版标识（例如 ISBN）、摘要、标签、分类、文件名和路径；支持多个词同时匹配和引号词组。
- 按格式、年份、分类、阅读状态筛选，支持排序；每页最多挂载 50 行，不为目录读取正文。测试覆盖 12,000 条检索及 4,000 条列表分页，未宣称特定硬件上的毫秒级性能。
- 单击查看元信息，方向键切换详情，双击或 Enter 阅读。分类、标签和未读/在读/已读状态可编辑；公共文献身份仍来自既有确认流程，不把用户整理字段冒充已确认书目数据。
- 导入支持多选和拖放，按文件内容 SHA-256 去重；失败文件单独报告。导入的书籍和文本可导出原始字节，或移出阅读库；后者保留笔记和 Agent 历史依赖的原件与对象引用。
- 阅读文件使用既有账号隔离的 ObjectStorage；原件是不可变 asset，目录是独立紧凑记录，提取正文是 `source.document` 实体。桌面资产落入当前数据保存位置，浏览器使用 IndexedDB，不新增安装目录以外的另一套数据根。
- 统一「位置与 Liteasy Path」入口展示真实保存位置。正文实体可按现有上下文预算解析；最多提取 2,000,000 字符并明确标记节选，长书不会绕过 Agent 的上下文预算。原始文件始终保留完整字节。

## 阅读器

EPUB 支持可重排的 EPUB 2/3 文本、书目元信息、spine、目录、内部链接和内嵌位图；Markdown 复用现有 MarkdownContent，支持公式、图表及允许的图片地址；TXT 支持 UTF-8、带 BOM 的 UTF-16，并对可识别的 GB18030 文本提供说明。单独导入的 Markdown 不会自动获取旁边的图片文件权限；可使用内嵌图片或 HTTPS 图片。

阅读提供章节目录、整书/本节搜索、字号、行距、宽度、纸白/暖纸/夜读/跟随应用主题、专注视图和按账号及文件隔离的阅读位置。一次只渲染当前章节；图片对象 URL 随章节切换和卸载释放。大段正文会分段，避免把整本书挂载到页面。

原文件上限 20 MiB，文本上限 8 MiB；EPUB 校验归档条目、路径、解压实际字节量和文档结构深度，单条目上限 8 MiB、累计解压上限 64 MiB。书内脚本、表单、外部样式和远程图片不执行。DRM、MOBI/AZW 及固定版式不属于可重排阅读支持范围。

## 明暗主题

「设置 → View → 外观」支持浅色、深色、跟随系统，保存在本机。FluentProvider、门户弹出层和全局语义色同步切换；生成主题保留其已有作用域，PDF 原纸张、图片与导出作品不通过全局滤镜反色。阅读纸张可以独立选择主题。

## 参考与验证

交互参考 [Zotero 的列表、搜索和元信息组织](https://www.zotero.org/support/quick_start_guide) 及 [Apple Books 的阅读外观控制](https://support.apple.com/en-au/guide/books/ibks8923126d/mac)。EPUB 解析依据 [EPUB 3.3](https://www.w3.org/TR/epub-33/) 和 [EPUB Reading Systems 3.3](https://www.w3.org/TR/epub-rs-33/)。实现遵循 Liteasy 现有 Fluent 2 组件、布局和统一资源边界。

验证分为解析与持久化回归、目录和阅读器交互、真实 AppShell 浏览器导入与重启测试，以及既有桌面 build、ci:smoke 和生成文件 cleanliness 检查。此次不改变 schema、锁文件或 Windows workflow。
