# 文献库、元信息与阅读外观

所有文件共用左侧「文献库」入口。保留原来的 PDF 目录、收藏、组织资源、推荐和分析选中集；EPUB、Markdown、TXT 与其他原文件接入本地文献库。选中文件后，最底部文件状态栏显示标题、作者、年份、出版物及标识；点击「元信息」可向上展开详情、摘要、分类标签和位置。独立的「书库与元信息」入口已移除，旧布局记录会归并到文献库，不删除已有资产。

## 文件管理

- 搜索标题、作者、DOI、出版标识（例如 ISBN）、摘要、标签、分类、文件名和路径；支持多个词同时匹配和引号词组。
- 本地文件筛选弹出层支持格式、年份和阅读状态；分类沿用原文献库筛选。文件列表每次增量显示 50 项，不为目录读取正文；PDF 继续保留原目录树。检索索引覆盖书目字段和文件路径。
- 单击查看元信息，方向键切换详情，双击或 Enter 阅读。分类、标签和未读/在读/已读状态可编辑；公共文献身份仍来自既有确认流程，不把用户整理字段冒充已确认书目数据。
- 导入支持多选和拖放，按文件内容 SHA-256 去重；失败文件单独报告。导入的书籍和文本可导出原始字节，或移出文献库；后者保留笔记和 Agent 历史依赖的原件与对象引用。
- 阅读文件使用既有账号隔离的 ObjectStorage；原件是不可变 asset，目录是独立紧凑记录，提取正文是 `source.document` 实体。桌面资产落入当前数据保存位置，浏览器使用 IndexedDB，不新增安装目录以外的另一套数据根。
- 统一「位置与 Liteasy Path」入口展示真实保存位置。正文实体可按现有上下文预算解析；最多提取 2,000,000 字符并明确标记节选，长书不会绕过 Agent 的上下文预算。原始文件始终保留完整字节。其他格式只保存原件并可导出，正文不做猜测性提取，也不自动执行文件。

## 阅读器

EPUB 支持可重排的 EPUB 2/3 文本、书目元信息、spine、目录、内部链接和内嵌位图；Markdown 复用现有 MarkdownContent，支持公式、图表及允许的图片地址；TXT 支持 UTF-8、带 BOM 的 UTF-16，并对可识别的 GB18030 文本提供说明。单独导入的 Markdown 不会自动获取旁边的图片文件权限；可使用内嵌图片或 HTTPS 图片。

阅读提供章节目录、整书/本节搜索、字号、行距、宽度、纸白/暖纸/夜读/跟随应用主题、专注视图和按账号及文件隔离的阅读位置。一次只渲染当前章节；图片对象 URL 随章节切换和卸载释放。大段正文会分段，避免把整本书挂载到页面。

原文件上限 20 MiB，文本上限 8 MiB；EPUB 校验归档条目、路径、解压实际字节量和文档结构深度，单条目上限 8 MiB、累计解压上限 64 MiB。书内脚本、表单、外部样式和远程图片不执行。DRM、MOBI/AZW 及固定版式不属于可重排阅读支持范围。

### PDF 导航

PDF 阅读器左栏提供目录、缩略图与批注。目录来自 PDF 内置书签，支持嵌套章节、命名目标、页引用和页内位置；没有内置书签时显示空状态，不以正文标题猜测目录。读取失败可重试，切换文档后旧请求不能触发跳转。

单击缩略图或批注按钮切换侧栏；双击会以 Pages 或全部批注替换正文阅读区；键盘聚焦按钮后按 Enter 也可展开。页面总览支持调整缩略图大小，点击页面返回正文。批注总览汇集当前文档的本地批注和已加载的团队批注，按原文顺序排列，支持摘录/备注/页码搜索与类型筛选，点击「定位原文」返回正文。文本框沿用 Markdown 渲染及附件解析；高亮、划线、便笺、文本框、手绘均可检索。返回按钮或总览区域内的 Escape 可返回阅读。

页面总览根据首页横竖比例分配行高，混合尺寸页面缩放到同一网格内；使用虚拟网格，缩略图仅在可见区域附近渲染，每份文档最多同时渲染两张，按显示尺寸与像素密度生成（最高 2 倍、单张最多约 100 万像素）。离屏和卸载时取消任务并释放画布；进入总览会卸载正文画布。批注初始展示 80 条，可继续加载，搜索覆盖全部已加载批注。上述限制针对新总览，不代表正文的所有页面已改成虚拟渲染。

交互结构参考本地 `tmp/zotero/reader/src/pdf/pdf-view.js`、`pdf-thumbnails.js` 和 `src/common/components/sidebar/outline-view.js`，实现使用 Liteasy 现有 PDF.js、Fluent 组件及批注存储。回归入口为 `pdfNavigation.test.tsx`、`PdfReaderInteraction.test.tsx` 和 `browser/pdfNavigation.browser.spec.ts`。

## 明暗主题

「设置 → View → 外观」支持浅色、深色、跟随系统，保存在本机。FluentProvider、门户弹出层和全局语义色同步切换；生成主题保留其已有作用域，PDF 原纸张、图片与导出作品不通过全局滤镜反色。阅读纸张可以独立选择主题。

验证分为解析与持久化回归、目录和阅读器交互、真实 AppShell 浏览器导入与重启测试，以及既有桌面 build、ci:smoke 和生成文件 cleanliness 检查。共享 schema、锁文件和 Windows workflow 不变。窗口装饰及能力配置见 workspace-shell.md。
