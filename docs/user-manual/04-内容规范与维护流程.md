# 内容规范与维护流程

## 单一来源与生成物

权威内容在 `03-integration/overlay/products/liteasy/apps/desktop/src/app/features/help/manual/`：`manifest.json` 管目录与元数据，`content/*.md` 管正文。`manualCatalog.ts`、离线 HTML、完整 Markdown 与目录表是生成物，不作为第二份源稿。用包内 `tools/build.py` 重新生成并运行验证。

应用运行时没有 Python 依赖；它使用已生成的 TS 静态导入和 Markdown。导出 HTML 的维护工具使用 Python 3 与 Mistune；只改应用注册表可用 `tools/generate-catalog.mjs`，无需额外 npm 包。

## 一篇文章的契约

标题写“做什么”，而非内部模块名。summary 解释结果与适用范围，不重复标题。id 采用稳定 `topic.task`，改标题不改 ID；迁移主题也不必改 articleId。kind 取 tutorial、how-to、reference、explanation。每篇必须有 condition、keywords、sourceIds、reviewedAt、baseline、related。

正文从二级标题开始，不含 YAML frontmatter，不依赖裸 HTML。步骤中优先写准确文本标签，其次写位置；不能只写“点右上角蓝色按钮”。一个动作有多入口时推荐一个，其他作为捷径；不要把所有快捷入口混进主流程。

步骤写完必须能回答：用户现在应该看到什么？失败时应该先检查什么？是否会联网、收费、写入、公开、覆盖或留下远端副本？这些条件写在动作之前或旁边，不以全局免责声明替代。

## 术语与命名

产品称 Liteasy；LiteasyClaw 只作为现有文件中的历史／技术名称，不让用户误以为两个必须分别安装的产品。统一“设置→AI 与助手→模型与连接”等当前路径。首次出现“修订、幂等、MCP、快照”时使用任务解释，技术细节留给参考篇。

强调已有语义差别：题录≠全文，生成≠导出，缓存≠备份，云同步≠实时协同，本机 MCP≠本地模型，取消≠撤销效果，应用版本≠数据格式版本。

## 状态词必须诚实

“代码已实现”需要实现依据；“测试通过”说明环境、范围和工具；“Windows 已验收”必须在最终安装包中完成实际流程；“生产可用”需要真实部署证据。禁止用“永不丢失、绝不联网、自动理解所有论文、任意格式导出、全平台完全一致”等不可验证承诺。

未知事实不要补得像真的：写出当前可用入口和替代路径，并把待核对项留在维护表。不能为了看起来全面而编一个恢复按钮、服务套餐或默认模型 ID。

## 更新步骤

1. 功能 PR 变更入口、默认值、权限、数据范围或格式限制时，同时更新对应 sourceIds 与正文。
2. 检查与之相关的其他文章，尤其是隐私总表、限制总览、设置地图和排错篇；只改一个教程不够。
3. 生成注册表和导出内容，运行静态／provider 测试、接入 fixture 测试，再在目标仓库跑相关回归。
4. 用真实最终版本复核高风险操作和截图；更新 reviewedAt 与 baseline。旧版本手册归档并注明适用范围，不覆盖成含糊的“最新”。
5. 合并前请一名不了解实现的人按步骤完成一次任务，同时请功能维护者核对平台／权限／数据边界。

这是建议流程，不在本包中指定真实团队负责人的姓名或承诺 SLA。可用 CODEOWNERS 将具体模块维护者加入对应文档审阅，接入前由团队决定路径规则。

## 国际化

本次只交付简体中文正文，不假装已提供英文翻译。请求其他语言时显式标注 zh-CN 回退；zh、zh-CN、zh-SG 和 zh-Hans 视为简体中文可用。繁体中文也应标注回退，不能只把 locale 改名视为完成翻译。

后续多语言保留相同 articleId，按 locale 存储正文，单独记录翻译版本和来源基线；不把界面翻译键与长篇手册绑定在同一个巨型 JSON。语言切换需要 Controller／UI 支持，本次不追加虚假的切换功能。

## 图像与许可

本包 SVG 为原创概念图，明确标注非产品截图。实拍截图使用干净测试账号与非敏感样本，脱敏凭据、用户目录、账号和未公开论文；同一幅截图保存平台、主题、版本、功能路径和 alt 文本。说明不能只存在于图片里。

不复制竞品截图、商标或字体文件作为 Liteasy 资产。外部文档只借结构与原则并给出处；项目自身代码的 fixture 保留来源说明，使用遵循原仓库适用的许可，不擅自给上游代码重新授权。

## 质量指标：先设目标，再做测量

建议记录新用户任务完成情况、找到文章所需步骤、无结果搜索词、错误路径是否能自助恢复。初期可做线下观察，不必立即引入遥测。若将来记录搜索词或反馈，应说明目的、选择权、保留期限与敏感词处理，默认不上传正文。

本包没有后台统计、反馈提交或真实用户研究结果；它交付可执行检查和建议测量方案，不编造满意度分数。
