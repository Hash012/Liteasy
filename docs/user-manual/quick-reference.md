# Liteasy 快速参考

## 先找对入口

F1 打开应用帮助；设置搜索用当前任务词。

| 操作 | Windows／Linux | macOS |
| --- | --- | --- |
| 打开文献库 | Ctrl + Shift + L | ⌘ + Shift + L |
| 开始 AI 对话 | Ctrl + Alt + I | ⌘ + Option + I |
| 打开设置 | Ctrl + , | ⌘ + , |
| 查看使用指南 | F1 | F1 |
| 回溯历史页面 | Ctrl + H | ⌘ + H |
| 切换活跃页面 | Ctrl + T | ⌘ + T |
| 查看全部快捷操作 | Ctrl + Shift + P | ⌘ + Shift + P |

## 三个检查

导入后能打开正文；保存后重开仍在；AI 结论能回到证据。

## 四个不要混淆

同步不是备份；题录不是全文；本机 MCP 不是本地模型；取消不是撤销已完成效果。

## 重要入口

模型：设置→AI 与助手→模型与连接。

目录：设置→文件与存储→数据保存位置。

同步：设置→同步与备份→WebDAV 同步。

增强推荐：设置→论文与推荐→论文推荐，默认关闭。

完整平台限制、隐私范围与排错见正式文章；本页不取代条件说明。
