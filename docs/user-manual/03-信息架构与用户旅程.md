# 信息架构、文章目录与上下文入口

所有 ID 为稳定内容路由；文章源稿位于 overlay 中 manual/content/。正文为单一来源，导出文件可再生成。

## 用户旅程

| 路线 | 经过的文章 | 完成判据 |
| --- | --- | --- |
| 首次阅读 | basics → import → selection → notes | 能重新打开正文和已保存笔记 |
| 带着问题使用 AI | chat → context → thin-reading → quality | 一条结论能回到原文；明确已读范围 |
| 组织研究证据 | metadata → boards.research → artifacts | 原文、推断、待验证内容可区分 |
| 保护并携带资料 | locations → backup → webdav → conflicts | 知道实际路径、同步范围和恢复副本 |
| 接入外部客户端 | local-mcp → batch-import → permissions | 先只读，写入可检查，撤销边界清楚 |

## 建议的上下文帮助接线

下面只列建议，不表示本包已经改动这些业务组件。使用 `useHelp()?.open({ providerId: "liteasy", articleId })`，不让 Markdown 执行业务命令。

| 用户所在位置 | 建议打开 | 动机 |
| --- | --- | --- |
| 模型配置旁 | agent.chat | 解释 API 基础地址和保存测试 |
| 选段工具栏旁 | reading.selection | 理解引用与定位失败 |
| 推荐隐私设置旁 | discovery.personalization | 在外发前说明默认值 |
| WebDAV 范围设置旁 | sync.webdav | 确认七类数据，而非只想象 PDF |
| 冲突提示旁 | sync.conflicts | 先保全两边，再决定版本 |
| 数据迁移按钮旁 | data.locations | 提醒保存、重启和旧目录保留 |
| 本机 MCP 设置旁 | integrations.local-mcp | 区分原生路径、客户端模型和写入权限 |
| 手机配对旁 | integrations.mobile | 说明真实部署和不唤醒关机设备 |

## 宽度与信息层级

应用帮助可能与阅读器并排：内容不能依赖全屏三栏。最小版本继续使用现有目录／结果／正文。独立浏览版的大屏文章采用主文＋页内目录，小屏将目录下移；长表格局部滚动。首页任务卡片是浏览版功能，应用内需另行实现。
