# Liteasy 开发协作提示词

这份文档把当前项目负责人对开发过程的关键要求整理成一份稳定提示词，方便后续：

- 换电脑继续开发
- 让其他开发者接手
- 让 AI 助手在新环境中保持一致风格

## 1. 使用场景

如果后续有新的开发者、外包成员、AI 编程助手或在其他电脑上继续开发，请先阅读这份文档，再开始修改代码。

## 2. 项目背景提示词

你正在参与开发 `Liteasy / LiteasyClaw`，这是一个桌面优先的科研 agent 工作台。项目当前阶段不是做完整产品，而是逐步实现 Phase 0-1 的桌面端核心骨架。

当前优先级：

- `desktop` 桌面端原型
- 本地文献工作区
- AI 助手 UI 和基础交互
- agent workflow 的可扩展工程骨架

不要把当前阶段当成成熟产品，也不要在没有需求确认的前提下超前加入复杂平台功能。

## 3. 强约束提示词

以下要求必须遵守：

### 3.1 直接在主仓库开发

- 当前开发直接在主仓库进行：`/home/octopus/Liteasy`
- 不要再把实现代码放到临时 worktree、`/tmp` 或其他外部目录
- 如果必须临时实验，最后要把源码明确迁回主仓库，并删除临时工作区

### 3.2 不要轻易提交 git

- 没有明确同意，不要主动提交 commit
- 没有明确要求，不要整理历史、改写 commit、强推或重置
- 不要用破坏性 git 操作

### 3.3 保持目录干净

- 不要让 `superpowers` 的过程文件和业务源码混在一起
- 业务代码放在：
  - `desktop/`
  - `docs/qa/`
- 方案和计划文档放在：
  - `docs/superpowers/specs/`
  - `docs/superpowers/plans/`
- 不要把临时导出、安装产物、截图、pdf、编译缓存混进源码目录

### 3.4 修改时优先保留功能可运行

- 清理目录时不要破坏：
  - `desktop/package.json`
  - `desktop/package-lock.json`
  - `desktop/src/`
  - `desktop/src-tauri/`
- 删除构建产物时，只删：
  - `desktop/node_modules/`
  - `desktop/src-tauri/target/`
  - 其他临时缓存

## 4. UI 与产品风格提示词

Liteasy 的桌面端 UI 目前有明确审美方向，参考现有设计图与产品截图。

### 4.1 默认风格要求

- 默认配色走 `浅蓝灰 + 奶白 + 细边框 + 弱阴影`
- 不要默认做成深色科技风
- 不要使用俗套的紫色 AI 风格
- 不要做得像通用 SaaS 后台

### 4.2 品牌要求

- 必须接入 `LiteasyClaw` Logo
- 品牌视觉应出现在应用主界面中
- Logo 大小要适合窗口，不要因为品牌区过高导致用户需要上下滚动整页

### 4.3 布局要求

- 默认窗口内应尽量完整显示，不要求用户上下滚动整个页面
- 如果内容超出，应优先让各栏内部滚动，而不是整页滚动
- 三栏结构必须清晰：
  - 左栏：文献库 / 推荐 / 收藏
  - 中栏：阅读与产物
  - 右栏：AI 助手

### 4.4 参考图遵循原则

- 不要求逐像素复刻
- 但要遵守相同气质：
  - 柔和
  - 轻盈
  - 学术感
  - 不是程序员工具风

## 5. 面向非开发成员的协作要求

项目里有人没有软件开发经验，所以开发过程中必须持续提供：

- 可读的 `README.md`
- 环境启动手册
- 阶段测试手册

写文档时必须假设读者：

- 不知道什么是 Tauri
- 不知道什么是 React
- 不知道命令行怎么排错

所以文档要写清楚：

- 去哪个目录
- 输入哪条命令
- 正常应该看到什么
- 失败时先检查什么

## 6. 开发流程提示词

### 6.1 当前实现方式

优先采用：

- 小步修改
- 能运行就验证
- 能测试就先写测试

对于行为变化和功能新增：

- 优先写最小失败测试
- 再写最小实现
- 再验证通过

### 6.2 当前阶段优先做什么

优先做：

- `workspace`
- `import`
- `assistant`
- `source-grounded answer`
- `skill-driven software control`
- `artifact`
- `phase1-test-guide`

不要提前重投入：

- 组织协作
- 插件生态
- 高级视频生成
- 复杂后台治理

## 7. 代码组织提示词

当前 `desktop` 目录下建议遵守：

- `src/app/layout/`：应用总布局
- `src/app/features/`：按功能拆模块
- `src/app/styles/`：全局样式与主题样式
- `src/tests/`：当前阶段测试
- `src-tauri/`：桌面壳与 Rust 入口

不要把所有逻辑都堆到一个文件里。

## 8. 启动与查看效果提示词

查看桌面端效果的标准方式：

```bash
cd /home/octopus/Liteasy/desktop
source "$HOME/.cargo/env"
npm install
npm run tauri dev
```

只看前端页面时：

```bash
cd /home/octopus/Liteasy/desktop
npm install
npm run dev
```
