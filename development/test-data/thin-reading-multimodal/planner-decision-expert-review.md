# 多模态生成决策盲审清单

判据：只根据输入判断，一张受控生成图是否比正文显著改善结构、过程、几何、比较或证据关系的理解。不要查看供应商录制字段或模型实际决策。

以下内容是与原始英文输入逐条绑定的审核用中文翻译；模型输入、响应和哈希均未改变。

每条必须且只能勾选一个选项，并在同一行 `理由：` 后填写至少 12 个字符的判断理由。完成后由领域专家运行清单中最后给出的命令。

## vector-database-taxonomy

标题：向量数据库管理系统综述

任务：生成一份解释系统分类框架的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 2 页 [evidence-vector-taxonomy] 该综述将向量数据库系统划分为索引、查询处理和存储组件，并说明这些组件之间的依赖关系。

- [x] 生成
- [ ] 省略
理由：系统组件及其依赖关系属于典型结构型知识，组件图可清晰呈现索引、查询、存储之间的关联，显著优于纯文字罗列，比文字描述更直观高效。
## bounded-quadratic-function

标题：有界二次优化实例研究

任务：生成一份解释该有界函数的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 3 页 [evidence-quadratic-domain] 对于闭区间 -1 <= x <= 5 上的 f(x) = x^2 - 4x + 3，顶点为 (2, -1)，两个端点的函数值分别为 f(-1) = 8 和 f(5) = 8。

- [x] 生成
- [ ] 省略
理由：二次函数在闭区间上的图像能直观展示顶点、端点值与开口方向，帮助读者快速把握最值位置，几何理解明显改善。
## circle-tangent-construction

标题：从圆外一点作切线

任务：生成一份解释该几何作图过程的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 4 页 [evidence-circle-tangent] 给定圆 O 和圆外一点 P，以 OP 为直径作圆；该圆与圆 O 的交点 T1 和 T2 即为切点，因为角 OTP 是直角。

- [x] 生成
- [ ] 省略
理由：圆与直径作图、切点定位是纯几何构造，插图可一步展示全部辅助线和直角关系，文字难以替代其空间直观性。
## cube-midsection-geometry

标题：立方体的平面截面

任务：生成一份解释该空间截面的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 5 页 [evidence-cube-section] 一个经过立方体六条适当选取的棱之中点的平面，会截得一个正六边形截面，其中两两相对的边互相平行。

- [x] 生成
- [ ] 省略
理由：三维立方体中的六边形截面极依赖空间想象，生成剖切示意图能清晰呈现中点连线和平行关系，大幅提升几何理解。
## projectile-motion-process

标题：无空气阻力的抛体运动

任务：生成一份解释该运动过程的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 2 页 [evidence-projectile] 在重力加速度恒定且没有空气阻力时，水平速度保持不变，竖直速度线性减小，因此物体在回到发射高度之前形成抛物线轨迹。

- [x] 生成
- [ ] 省略
理由：对于抛体运动的速度分量变化和抛物线轨迹的理解依赖于受力分析和运动分析，用轨迹图配合受力与速度的矢量箭头能直观展示水平匀速、竖直匀减速的过程，优于纯公式描述，和读者手动分析的过程更贴合，便于理解记忆。
## methane-combustion-sequence

标题：甲烷燃烧的化学计量关系

任务：生成一份解释该反应的薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 6 页 [evidence-combustion] 配平后的总反应为 CH4 + 2 O2 -> CO2 + 2 H2O；现有证据只确立了总反应的化学计量关系，并未确立分子反应机理。

- [ ] 生成
- [x] 省略
理由：仅给出总反应方程式，未涉及分子尺度步骤或中间体，图示无非是原子重排的静态示意，对理解整体计量比无实质性增益。
## single-term-definition

标题：统计功效术语说明

任务：生成一份薄读总述，并且仅当生成图能够实质提升理解时才请求可视化。

证据：
> 第 1 页 [evidence-power-definition] 统计功效是指：当某个给定的备择假设为真时，假设检验拒绝原假设的概率。

- [ ] 生成
- [x] 省略

## unsupported-reaction-mechanism

标题：催化反应的实测产率

任务：生成一份薄读总述，并且仅当生成图能够实质提升理解时才请求可视化；不得推断证据不支持的反应机理。

证据：
> 第 7 页 [evidence-catalytic-yield] 在报告的实验条件下，催化剂使分离产率从 41% 提高到 68%；实验没有测量任何中间体物种或基元反应步骤。

- [ ] 生成
- [x] 省略

## plain-limitations-statement
