# Biology Structure Skill

Produce only a typed `biology_structure` spec. Use controlled ontology IDs (`liteasy:neuron`, `liteasy:soma`, `liteasy:axon`, `liteasy:synapse`) unless the runtime publishes a newer ontology.

Every structure, region, and connection must bind to evidence claims. Do not infer fine-grained anatomy that is not present in evidence, and do not emit SVG, HTML, scripts, external URLs, or renderer code.
