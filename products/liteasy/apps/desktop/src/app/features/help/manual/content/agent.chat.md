## 配置自己的模型
1. 打开 **设置 → AI 与助手 → 模型与连接**，选择 **自备 API key**。
2. 选择服务商，填写该账号可用的模型 ID、API 基础地址和密钥。预设不是服务商额度、地区或模型可用性的保证。
3. 基础地址保留服务商要求的版本路径，不要自行追加 `/chat/completions` 或 `/messages`。专属域名、部署名或接入点以自己的控制台为准。
4. 点击 **保存并测试**，查看实际返回。测试会消耗相应服务额度。
5. 打开 AI 对话，选择可用模型，先发一句不包含敏感内容的问题，再加入论文引用。

## 保存密钥的边界
桌面版通过系统凭据库保存密钥，按服务商和 API 地址隔离。已有密钥留空可保留；更换地址后需要为新地址保存密钥。系统凭据库不可用时应显示错误，不以普通明文设置替代。

浏览器预览只在当前页面会话保留密钥，刷新需要重填，也可能受 CORS 限制。不要把“预览版刷新丢失密钥”当成桌面凭据库损坏。

## 第一次论文提问
使用 **@** 引用目标论文或把资源拖入对话，检查上下文条目，再提出一个明确问题。例如：“从当前可用正文说明方法输入和输出；无法确定的部分请标为未知。”没有资料引用时，回答可能只是模型的一般知识。

## 不成功时
先检查模型测试，再检查论文是否可读取。401／403 通常要核对身份与权限，429 要查看额度或限流提示；具体原因以服务商返回为准。不要在公开 issue 中粘贴密钥或完整请求头。
