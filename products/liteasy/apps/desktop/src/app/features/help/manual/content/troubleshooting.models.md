## 第一步：确定是哪条连接
普通 AI 对话使用模型连接；元信息与推荐使用文献服务；OCR／多模态解析使用各自服务；WebDAV 是另一条链路。不要用“AI 能回答”推断其他服务应当可用。

## 常见现象与检查
| 现象 | 可采取的检查 |
| --- | --- |
| 401 或身份错误 | 密钥是否属于当前服务商与地址；是否已保存 |
| 403 或权限拒绝 | 模型、部署、地区、组织或账号权限；以返回消息为准 |
| 404 或接口不存在 | 基础地址、版本路径和模型／部署 ID 是否正确 |
| 429 | 查看配额和限流提示，减少并发并按服务建议重试 |
| 连接超时 | 核对网络、代理和服务状态，先用短请求测试 |
| 拒绝 response_format | 在高级设置中尝试“按提示生成 JSON”，并核对后续结果 |
| 浏览器 CORS 失败 | 区分预览和桌面原生请求，不能简单归因为密钥错误 |
| 更换地址后认证失败 | 凭据按服务商与端点隔离，为新地址保存对应密钥 |

状态码只是一条线索，不保证错误一定由表中的原因引起。不要为排错关闭 TLS 校验、把密钥放进 URL 或把秘密写进公开日志。

## 最小复现
先在 **模型与连接** 使用 **保存并测试**；成功后测试一句普通对话；再加入一小段可读文本；最后测试整篇论文或结构化产物。这样能判断问题是在连接、正文读取还是特定生成格式。

增强推荐的向量／重排接口独立配置；回退本地匹配后仍有推荐结果，不代表外部语义服务已经正常。保存测试结果时保留模型和端点类型，去掉凭据与敏感查询参数。

## 费用提醒
连接测试和重复生成可能产生真实费用。取消或客户端报错不保证服务商没有处理请求；先查看实际使用记录再连续重试。
