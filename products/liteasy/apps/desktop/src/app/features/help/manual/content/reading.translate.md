## 查词和短语翻译
打开 **设置 → 外观与阅读 → 查词与选段翻译**，检查词典、翻译服务、源语言、目标语言和自动查询。需要自部署 LibreTranslate 时填入对应服务地址；不要把模型 API 地址填进词典接口。

回到正文，先用一个可复制的单词或短语验证结果，再尝试较长选段。自动查询会在相应操作触发后调用配置的服务；处理敏感文本时先核对服务去向，必要时关闭自动查询。

## 论文翻译与普通查词不是同一条链路
模型分析和翻译使用可用的模型连接，而选段工具中的词典或独立翻译服务可能有自己的配置。某个入口成功，不说明另一个服务也已经配置完成。

译文帮助理解，不取代原文证据。研究结论、数值、否定词、比较对象和适用条件，应回到原文核对。不要根据译文反向猜测 PDF 高亮坐标。

## 扫描件没有可复制文字
在 **设置 → 论文与推荐 → 论文解析与薄读** 检查 OCR 语言与论文解析服务。先确认该服务确实可用、需要哪些权限及是否会上传文件，再对非敏感的小样本测试。

解析服务、云端多模态和自备模型密钥并不共享同一组权限。没有解析结果时，应明确记录“缺少文本”，不要让 AI 凭题名生成看似完整的论文解读。

## 成功检查
选定的原文与词典结果对应，译文语言正确，扫描件识别后能复制具有意义的连续文字。图表、公式识别仍需人工核对；“任务完成”不保证每个字符都正确。
