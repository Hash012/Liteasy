> 增强推荐在该代码基线中默认关闭；真实模型质量、人评与 Windows 性能仍有待验收。本功能说明不承诺推荐一定更准或更快。

## 先从本地增强开始
1. 打开 **设置 → 论文与推荐 → 论文推荐**。
2. 开启 **增强关联推荐**，分别决定是否纳入批注／笔记和已确认画像。
3. 保持 **允许向外部服务发送笔记、批注和画像** 关闭，先观察本地匹配是否满足需要。
4. 对一两个熟悉主题检查结果和理由，判断新增资料是否真的帮助筛选。

## 需要外部向量或重排服务时
配置独立的向量、重排接口，使用 **测试并保存** 验证响应与维度。普通聊天模型连接不等于已经有可用的 embedding 或 reranker 服务。更换模型或端点会隔离索引，不能因为向量维度相同就混用。

只有明确接受资料发送到相关服务后，才开启外发授权；核对发送范围和服务商条款。远程端点要求 HTTPS，本机服务可按实现使用 HTTP。不要在普通配置说明中粘贴真实密钥。

## 失败时会怎样
未配置语义服务或调用失败时，系统可回退到本地词项匹配。出现结果不代表向量服务成功运行；查看实际状态，再判断是否需要排错。

## 清理缓存
清除检索缓存不会删除论文、笔记或白板资产，但会停用增强推荐；重新开启后按需建立缓存。语义索引是可重建缓存，不在 WebDAV 工作区导出范围中。不要为了清缓存删除整个 LiteasyData。
