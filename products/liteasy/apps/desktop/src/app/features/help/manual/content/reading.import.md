## 导入本地文件
1. 打开 **文献库**，先定位目标目录，再点击标题旁的 **导入文件**。
2. 选择支持的文件。也可以把文件拖到文献库的目标目录上；出现目标高亮后再松开。
3. 导入完成后在当前目录或搜索框查找题名、文件名。已有元数据时，显示题名可能与磁盘文件名不同。
4. 单击核对底部信息，双击打开内容。能看到文件条目但不能打开正文，不能算阅读链路已经成功。

## 推荐的组织方式
先用少量明确的目录区分“待筛选、正在研究、已完成”，再用标签表达交叉主题。不要一次导入巨量材料后才检查格式和目录；先用几份真实样本确认行为。

## 支持格式与边界
PDF、EPUB、Markdown、TXT，以及受支持的 MOBI／兼容 PRC、AZW、FB2、HTML 可作为阅读内容。纯 KF8／AZW3 和受 DRM 保护的电子书不属于当前支持范围。文件图标支持某种类型，不代表它具备相应的完整编辑器。

## 重复和失败
在线论文下载按 PDF 内容做重复检测，重复文件可能沿用已有记录而不新增第二份。不要将这个规则外推为所有导入渠道都会按题名自动合并。

找不到文件时先清除搜索和分类筛选，再核对目标目录、当前账号与文献库。遇到损坏文件、权限拒绝或不支持的格式，保留原文件，不要更改扩展名冒充其他格式。先确认能用合适的原生阅读器正常打开，再整理最小复现资料。
