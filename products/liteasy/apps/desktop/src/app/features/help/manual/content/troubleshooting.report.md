## 提交前删除这些信息
API key、Authorization 请求头、访问令牌、同步口令、WebDAV 密码、私有连接文件、Cookie、真实个人信息，以及不应公开的论文或笔记内容。URL 查询参数也可能包含敏感信息，路径可隐去用户名但保留结构。

模型问题保留服务商、协议和模型类型通常有帮助，但不要上传密钥；文件问题保留格式、页数和大小；同步问题保留类别、状态和是否等待重启。日志路径依具体版本而定，不凭空猜测并要求你扫描整个磁盘。

## 通过哪里提交
使用项目维护者指定的反馈渠道，或在允许公开时使用仓库的问题入口。本离线手册的“复制问题模板”只在本机生成文本，不上传反馈、不自动创建 issue，也不收集阅读内容。

## 维护者需要区分的结果
源代码阅读、单元测试、浏览器测试、Windows 安装启动、真实服务联调与生产验收是不同证据。报告清楚自己的环境，能避免把某一层成功误解为全链路成功。
