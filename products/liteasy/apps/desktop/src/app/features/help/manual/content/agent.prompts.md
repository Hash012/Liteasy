## 修改默认设置
在 **设置 → AI 与助手 → AI 生成提示词** 中找到对应生成任务，调整默认系统提示词与风格。不同任务用途不同，不要为了让薄读更详细而把所有生成任务都换成同一段提示。

## 只调整这一次
在 AI 论文工作台选定能力后，通过本次提示词编辑器补充要求。单次修改只影响当前生成；它适合演示时长、比较维度和特定受众，而不是全局长期偏好。

## 写什么更有效
明确输入范围、读者背景、输出结构和不确定性的表达方式。例如：“先解释用途，再解释机制；数字保留单位；每个结论说明来自原文还是推断；没有证据不补全。”这是一种可验证的风格，比“写得高级、越全面越好”更容易验收。

## 做一次小对照
用同一篇论文和同一模型先生成基线，再只改一项提示要求。检查你在意的维度是否改善，例如证据可追溯、术语准确或解释顺序。不同输入、模型和提示同时变化时，不容易判断原因。

## 安全边界
提示词不应包含 API key、密码或固定访问令牌。提示词不能赋予不存在的读取权限，也不能保证模型绕过上下文和输出限制。要求“永远正确”不是质量控制，仍需核对原文。

## 维护自己的模板
将满意的任务描述保存在普通 Markdown 笔记，注明适用场景和日期。只有在当前扩展或工作流界面确实提供对应能力时，再迁移为可执行流程；不要把一段说明文字自动当成已经安装的 Skill。
