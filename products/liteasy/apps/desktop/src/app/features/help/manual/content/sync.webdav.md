## 首次连接
1. 打开 **设置 → 同步与备份 → WebDAV 同步**，填写自己服务的 HTTPS 地址、用户名和相应密码／应用密码。不要把账号密码写进 URL。
2. 使用界面中的连接验证功能，确认服务具有实际读写和清理测试文件的权限。
3. 检查下表范围，尤其是默认开启的对话和画像类别。用少量非敏感资料执行第一次同步。
4. 在另一台兼容版本设备上连接同一同步空间，检查下载结果与需要重启应用的数据。

## 当前分类默认值
| 类别 | 默认 | 主要内容 |
| --- | --- | --- |
| 文献与本地文件 | 开启 | 库内非隐藏普通文件及独立题录 |
| 论文批注与阅读产物 | 开启 | 论文伴生批注和阅读数据 |
| Liteasy 笔记、白板与产物 | 开启 | 对象、版本、关联附件及产物 |
| AI 对话历史 | 开启 | 对话快照，不恢复正在运行的任务 |
| 偏好设置与用户画像 | 开启 | 外观、连接配置、画像和研究行为等 |
| 外部链接目录 | 关闭 | 已授权连接的文件夹／文件，例如 Vault |
| API key | 关闭 | 单独加密的模型和论文服务凭据 |

这些是启用 WebDAV 后的类别默认值，不表示应用已替你自动连接某个服务器。

## 必须知道的限制
关闭类别只是暂停传输，不删除远端内容，也不清除该类别的历史比较基线。外部目录目前是类别级开关，不是每个文件夹一个开关；隐藏目录、符号链接和 Windows 目录联接不纳入遍历。

此协议用于 Liteasy 设备，不导入 Zotero 的 WebDAV 数据。不要把两种应用的同步空间当成同一个文件格式使用。同步不是整个 AppData 的镜像，也不是多人实时协同编辑。

## 同步完成后
普通文件与应用工作数据的应用时机不同；部分下载的工作数据进入恢复队列，在下次启动时应用。看到上传／下载结束后，仍要检查冲突、延迟应用提示，并重新打开目标内容验证。
