## 平台与服务
| 能力 | 本次已核对的边界 |
| --- | --- |
| 浏览器预览 | 密钥只在页面会话，可能受 CORS 与文件授权限制 |
| 桌面密钥 | 系统凭据库；不可用时报错，不降级明文持久化 |
| 本机资产 MCP | 桌面本机 STDIO；每次启动需启用，账号切换撤销；Windows 真实联调仍需验收 |
| 评论 Review | 仅 Linux／macOS 桌面；Windows／浏览器暂不支持；只读共享快照 |
| 手机任务 | 同账号同 API、原生 OAuth、桌面在线；不能唤醒关机设备；生产实链路需验收 |
| 云服务 | 代码中有实现，不代表安装所连接的生产服务已部署完成 |
| 增强推荐 | 默认关闭；人工质量和 Windows 性能指标未在本包中验收 |

## 格式与数量边界
| 项目 | 当前说明 |
| --- | --- |
| 电子书 | 不支持纯 KF8／AZW3 与 DRM；MOBI 兼容正文另论 |
| MCP 在线论文导入 | 每批最多 50 篇；任务历史有会话边界 |
| MCP 正文读取 | 默认 12,000、最多 80,000 个 UTF-16 字符；使用 nextOffset 分页 |
| 原生全文下载 | 最新链路 256 MiB 上限；不外推浏览器或其他入口 |
| WebDAV 普通文件 | 256 MiB 上限 |
| WebDAV 目录／对象快照 | 约 128 MiB 级限制；大型 Vault 尚无完整分块快照 |
| 外部目录同步 | 默认关闭；类别级选择；隐藏目录及链接遍历受限 |
| 全库同步 | 不包含所有缓存、OAuth 会话、运行中任务和其他账号对象 |

## 如何使用这张表
这些边界用于判断任务是否适合当前实现，不是速度承诺、稳定性认证或所有调用入口的统一配额。服务商限流、模型窗口、站点授权和你的网络还会增加独立限制。

原始材料依据 0.1.28 源码快照编写；本次整合补充了后续引用等功能的说明。本文不代表已在实际 Windows 安装包、用户付费模型或用户真实 WebDAV 上完成验收。软件升级后，应重新检查这里的范围，不能永久沿用历史数值。
