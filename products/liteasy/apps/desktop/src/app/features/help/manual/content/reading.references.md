# 文件链接与片段引用

在笔记、论文笔记和导入的 Markdown 编辑器里，可以引用其他文件。阅读视图、对话和其他使用通用 Markdown 显示组件的页面共用引用预览能力。

## 插入链接

1. 输入 `[[`，编辑器会自动补全 `]]`，光标留在括号中间。
2. 输入文件或论文名字，从候选中选择；也可以点击括号内圆角 **+**，打开与 AI“添加上下文”共用的浮窗。
3. 选择整份文件，或打开其内容继续选择章节、行范围或文字。按 Escape 可收起候选；双击已有双括号链接可重新编辑。

同名文件请使用选择器区分路径。选择器可能插入完整 Liteasy Path 并用别名显示文件名；保留完整路径有助于准确找到目标。

## 链接与嵌入语法

```markdown
[[CicN]]
[[CicN#Title1]]
[[CicN#L1:3]]
[[CicN|我的笔记]]
![[CicN#Title1]]
[我的笔记](liteasy://objects/实际对象标识)
[同目录笔记](./CicN.md)
```

`#Title1` 包含该标题和其子标题的内容，直到下一个同级或更高层级标题。`#L1:3` 是源文本第 1 至第 3 行，两端均包含在内。重名标题可以改用行范围；行号从 1 开始。示例的“实际对象标识”需要替换为资产的真实 Liteasy Path。

## 在预览中选取内容

输入并选中文件后，内容浮窗显示标题和行号。点击标题选取章节；点击起始行，再按住 Shift 点击末行，选取连续行。也可以直接拖选文字，再使用选择器的添加操作。相同界面用于 AI 上下文，免去在不同入口重复定位。

长文分段显示，初次只加载有限文本；需要更多内容时按界面提示继续加载。单次预览最多读取 80,000 字符，超出时不能把已显示部分当作全文。PDF、电子书预览使用提取文本，行号不等于原始页面位置。

## 阅读时查看引用

将鼠标停在链接上，稍候出现小型预览浮窗；键盘聚焦链接也可查看预览。点击链接打开目标文件。当前点击后打开的是文件，不保证定位到其原始页面中的精确位置。

在双括号或 Markdown 链接前加 `!` 可嵌入内容。嵌入按需加载，并限制嵌套深度；循环引用或无法读取的目标会显示提示，不会无限展开。

## 修改文件后需要注意什么

普通链接读取当前可用内容；AI 上下文片段固定为添加时的版本。文件改名、标题改名或插入行之后，名称、标题及行号引用可能需要重新选择。外部目录中的变更可通过重新载入获取；不能将预览缓存当作磁盘监控。未导入目录中的文件不会因为输入一个路径就自动获得访问权限。
