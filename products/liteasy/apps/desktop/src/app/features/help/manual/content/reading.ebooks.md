## 选择可读格式
| 格式 | 当前边界 |
| --- | --- |
| EPUB、Markdown、TXT | 现有阅读链路支持 |
| MOBI、兼容 PRC／AZW | 支持兼容正文；不是所有 Kindle 格式的统称 |
| FB2、HTML／HTM | 支持相应正文与允许的资源，文件中的脚本不执行 |
| 纯 KF8／AZW3、DRM 文件 | 当前不支持，需从合法来源取得兼容的非加密格式 |

某种类型有专属文件图标，不代表它有完整编辑、排版转换或导出能力。不要把 `.azw3` 改名为 `.mobi` 作为转换方法。

## 阅读与调整
导入文件后双击打开；通过 **设置 → 外观与阅读** 调整阅读字体和字号。桌面可以读取系统字体；浏览器可能需要你主动授权字体访问。选择字体不会自动下载或安装字体。

对较长内容，先检查章节和几处正文是否正确，再把它提供给 AI。章节预览和按需加载能减少一次性渲染压力，但不能保证损坏文件可恢复。

## Markdown 的两种情况
作为阅读文件导入的 Markdown，与通过已授权文件夹连接后直接编辑的 Markdown，写入能力可能不同。连接 Vault 的正文编辑会涉及真实磁盘文件；普通只读来源可另建笔记保存自己的分析。

## 遇到乱码、缺图或打开失败
先核对真实格式与文件完整性；对 HTML 或电子书，资源可能不在允许范围内。保留原文件，用可信工具检查。不要为恢复排版而允许陌生文件执行脚本，也不要绕过版权或访问控制。
