## 先保全，再判断
先保存正在编辑的文字。出现冲突、格式错误或迁移错误时，保留原件和恢复副本，不先卸载、清缓存、删数据库或重装整个资料库。

## 按现象分流
| 现象 | 第一项检查 | 下一步 |
| --- | --- | --- |
| 本地 PDF 无法打开 | 原文件能否在其他阅读器打开 | 搜索“PDF 和文件排错” |
| 有页面但无法选字 | 是否有真实文字层 | 检查扫描件识别和解析服务 |
| 普通对话就失败 | 模型保存并测试是否成功 | 搜索“模型与联网服务排错” |
| 聊天成功、推荐失败 | 选定文献服务是否可达 | 不要反复更换模型密钥 |
| 看不到已保存笔记 | 当前账号、库、筛选和附属资源 | 核对数据路径，勿直接重建库 |
| 同步后另一端没变化 | 是否有冲突或待重启应用的数据 | 搜索“同步排错” |
| MCP 无法连接 | 桌面是否运行且本次已启用 | 重新复制真实路径配置并重连 |

## 一次只改一个变量
用一个小 PDF、一篇测试笔记和一条短问题重复操作。记录改了哪个设置和结果，不在同一轮同时改模型、服务地址、数据路径和代理。

## 什么证据有用
应用版本、操作系统、桌面或浏览器、发生步骤、预期与实际结果、脱敏错误全文，以及是否能用新建测试资料复现。浏览器前端测试通过，不能证明 Windows 原生文件和凭据链路也通过。

## 何时停止继续尝试
遇到未知数据版本、重复覆盖冲突、持续迁移失败或疑似凭据泄露时，先停止相关写入／同步，保存副本并联系维护者。继续试错可能让原本可恢复的问题变得复杂。
