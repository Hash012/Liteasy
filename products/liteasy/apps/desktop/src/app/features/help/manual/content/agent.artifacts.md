## 开始前
先导入并确认要使用的论文有可用全文，再测试模型连接。输出的组织形式不会自动提高输入证据的质量；两篇无关论文也不会因生成对比表而具备可比性。

## 生成流程
1. 点击顶栏 **AI** 打开论文工作台，在 **近期论文** 或 **文献目录** 中选择来源。
2. 核对已选数量，点击 **确认选择**。需要改变来源时，修改后重新确认。
3. 选择 **生成提纲**、**生成 PPT**、**生成思维导图** 或 **生成对比表**。
4. 在本次提示词中写清受众、目标、篇幅和比较维度，点击 **开始生成**。
5. 查看结果并核对来源；只有界面明确报告保存或导出成功，并能重新打开相应内容，才算完成交付。

## 如何选择能力
提纲用于论证顺序；PPT 用于讲述和演示；思维导图用于概念关系；对比表用于统一维度下的差异。对比表应先指定维度，如数据规模、读写模型、正确性假设与实验硬件。

示例提示：“面向已经学过数据库基础的读者，生成一份讨论提纲。每一节只保留一个核心问题，结论附原文出处；缺少实验条件的条目标为待核实。”

## 不要混淆生成与文件导出
当前工作台代码确认了五种生成入口，但不据此承诺所有产物都能一键导出为任意外部格式。使用实际版本提供的保存、下载或导出入口；需要 `.pptx` 等具体格式时先确认该版本的真实出口，再安排交付。

## 失败或等待很久
检查任务状态、模型返回和输入规模。重复点击可能产生多次请求或费用；先确认上一项是否完成，再重试。退出应用前保存编辑并等待正在运行的任务结束。
