# 开始使用 Liteasy

## 导入并阅读文件

1. 点击最左侧书本图标，打开**文献库**。
2. 点击文献库标题旁的**导入文件**，选择 PDF、电子书、Markdown 或文本文件。也可以把文件拖到目标目录上导入。
3. 单击条目选中并查看底部元信息，**双击**条目在中间栏阅读。论文图标左侧的 **+N** 展开附属笔记、图文及其他资源。
4. 右键文件可设置分类与标签。用库顶端搜索框和筛选按钮按作者、年份、学科或标签定位文件。

## 沉浸阅读与全屏专注

- 连续**三击文件条目**，或三击中间栏的阅读标签，进入只保留阅读区的沉浸模式。也可从顶栏的**布局 → 沉浸阅读**进入。
- 按 **F11** 进入全屏专注，再按一次恢复窗口与原有布局。
- 鼠标移到屏幕上、下、左、右边缘，可临时展开工具、底部面板或侧栏；移回正文后自动收起。顶部提供退出按钮。
- 按 **Esc** 退出沉浸阅读。已展开的菜单或对话框会先关闭；原有分栏、阅读内容和未发送草稿保留。

## 发起第一次 AI 对话

1. 点击最左侧机器人图标，打开 **AI 对话栏**。
2. 首次使用先在**设置 → AI 与助手 → 模型与连接**中配置可用的模型连接。可以使用自己的模型 API；保存后检查连接并选择模型。
3. 在消息输入框输入问题并发送。使用 **@** 引用论文或其他资源，使用 **/** 查找可用能力；也可以将资源拖入对话作为上下文。
4. 要进行薄读、生成提纲或 PPT，可点击软件顶栏的 **AI**，先选择论文，再选择对应能力。正在阅读的论文也可以直接点击阅读器上方的 **AI 薄读**。

## 找到设置与帮助

- 点击左侧齿轮图标打开中间栏的**设置**，搜索“模型”“主题”“保存位置”等关键词。
- 没有打开中间栏内容时，开始页会显示可点击入口和快捷键。关闭中间栏标签后会再次显示。
- 点击左侧问号图标或按 **F1** 打开离线使用指南。
- **查看全部快捷操作**支持输入关键词查找功能，方向键选择、Enter 执行、Esc 关闭。
