## 先问四个问题
谁会获得数据？范围是一个选段、一篇论文还是整类资料？只是读取，还是可以改写？关闭之后，哪些已经发生的效果仍然保留？

## 常见误解
| 你做的操作 | 实际边界 |
| --- | --- |
| 关闭 WebDAV 类别 | 暂停后续传输，不删除远端已有内容 |
| 关闭 API key 同步 | 不撤销其他设备已拿到的密钥 |
| 停止评论共享 | 阻止后续读取，不收回客户端已接收的数据 |
| 关闭 MCP 或撤销写入 | 旧连接失效，已提交的修改不自动回滚 |
| 取消批量导入 | 未完成工作停止，已导入文献保留 |
| 取消手机任务 | 不撤销已完成动作、在途提交或已发生模型费用 |
| 关闭文档标签 | 关闭视图，不等于删除资源 |
| 完成数据迁移 | 旧目录保留，需要另行决定何时处理 |

## 启用写入前
先用只读模式确认当前账号、资料库和资源身份。允许写入后，让客户端读最新版本，明确追加或替换范围，并在真实目标处核对结果。不要授权一个只需总结的任务修改所有笔记。

## 共享前与结束后
共享前检查敏感内容和接收方，尤其是共享工作区；结束后主动停止。凭据不要出现在聊天、URL、终端录屏、公共截图或问题报告中。

## 不确定是否执行成功
超时、进程退出或网络断开不一定等于没有执行。先查目标内容、版本、同步状态或服务商使用记录，再决定是否重试。需要恢复时保留两边副本与错误证据，避免连续重试造成更大范围变化。
