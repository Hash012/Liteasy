## 先看实际路径
打开 **设置 → 文件与存储 → 数据保存位置**，查看 **当前目录**，可选择 **打开数据文件夹**。Windows 新安装默认位置与已有安装、自定义目录可能不同，实际路径以这里显示的值为准。

该数据目录包含文献库、笔记对象、聊天历史和生成内容等应用数据；外接文件夹和单独指定的文献库保持各自位置，不能假定一次迁移就会把所有外部资料搬走。

## 在应用内迁移
1. 保存所有笔记和编辑，等待生成任务及同步结束；重要资料先做独立备份。
2. 点击 **选择数据保存位置**，选择新位置。应用将在目标下创建 LiteasyData，先核对显示的待生效路径。
3. 需要撤回时点击 **取消目录更改**，不要直接删目标中的文件。
4. 确认后点击 **重启并迁移数据**。重启时复制并校验现有数据，成功后使用新目录，旧目录保留。
5. 重新启动后查看当前路径，打开几份原文、笔记、白板和对话，检查内容，再确认外接目录是否仍可访问。

## 迁移失败时
保留旧目录和界面错误信息，不要反复手工拼接两份数据库，也不要删除旧数据来强迫切换成功。核对磁盘空间、目标写权限和外部程序占用，再向维护者提供脱敏的路径与错误。

## 与同步的区别
数据迁移改变本机保存位置；WebDAV 在设备间传输选定逻辑数据；备份保存可恢复的独立副本。三者不能互相替代。浏览器预览的数据保存在当前浏览器，不能按桌面原生迁移流程操作。
