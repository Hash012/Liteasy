## 默认行为
WebDAV 的 **API key** 类别默认关闭。模型连接配置与实际密钥不同：同步了服务商、模型和地址，不代表另一台设备已经获得密钥。

## 明确需要时再开启
1. 先确认 WebDAV 连接、其他数据同步和自己的账号范围正确。
2. 在 API key 同步选项中额外设置至少 12 字符的同步口令；各设备使用同一口令。将口令保存在自己的密码管理器，不放进聊天、源码或截图。
3. 启用密钥类别，完成同步，再在目标设备测试一条非敏感的模型请求。
4. 核对新设备使用的服务商和端点，避免把不同地址的凭据混淆。

## 什么被同步，什么不被同步
当前范围包含已配置的模型与论文服务的系统凭据，作为独立加密包传输。登录 token、WebDAV 密码和 MCP token 不在该范围内。缺失条目不会用来删除另一设备已有凭据。

同步口令保存在本机系统凭据库；实现使用口令派生与认证加密。**这不意味着所有 WebDAV 文献、笔记和对话都做了相同的端到端加密。** 普通资料仍需要按服务器实际安全能力和访问权限评估。

## 口令错误或凭据库不可用
先停止反复重试，核对两端口令和系统凭据存储。不要把密钥改存到普通 JSON 作为变通，也不要假定团队能替你找回口令。保留错误提示，必要时在各设备重新配置自己的服务密钥。

## 撤销边界
关闭类别只停止后续传输，不保证删除服务器已有加密包，也不会撤销另一设备已经取得的凭据。怀疑密钥泄露时，需要到相应服务商撤销或轮换，而不只是关闭 Liteasy 同步。
