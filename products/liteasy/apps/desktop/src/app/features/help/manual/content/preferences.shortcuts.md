## 全局快捷操作
以下表格由应用实际命令注册表生成。Windows／Linux 使用 Ctrl，macOS 使用 Command；Option 对应 Alt。输入法组合输入、重复按键等情况下，快捷键不会被简单地当成普通命令执行。

## 阅读与白板局部操作
| 位置 | 操作 | 按键或交互 |
| --- | --- | --- |
| 阅读工作区 | 全屏专注 | F11，再按恢复 |
| 沉浸阅读 | 退出 | Esc；先关闭已展开菜单或对话框 |
| 文献条目 | 打开正文 | 双击；单击只选择并查看信息 |
| 阅读条目或标签 | 进入沉浸 | 连续三击；也可用布局菜单 |
| 白板 | 全选卡片 | Ctrl／Command + A |
| 白板 | 平移 | 空格或中键拖动 |
| 白板 | 缩放 | Ctrl／Command + 滚轮 |
| 白板 | 适应内容 | Shift + 1 |

## 不生效时先检查
焦点是否在文本输入框、菜单或对话框中？系统或浏览器是否抢占了相同键位？你正在使用桌面安装版还是浏览器预览？先尝试相应菜单入口，勿通过清空设置解决一个被其他界面捕获的按键。

“查看全部快捷操作”支持搜索、方向键选择、Enter 执行和 Esc 关闭。它与 AI 输入框的 **/** 能力列表不是同一个入口。
