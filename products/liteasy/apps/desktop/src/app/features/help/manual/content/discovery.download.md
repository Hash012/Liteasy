## 从推荐详情开始
打开论文详情，核对题名、作者和稳定标识，再使用下载或获取全文入口。系统会尝试已知 PDF、论文页面和精确题录提供的位置；只有一个 URL 或“开放获取”字段，不代表文件已经下载成功。

选择文献库内目标目录；未指定时使用相应流程的默认 `Download` 目录。完成后核对实际保存位置，再从文献库双击 PDF，检查首页和题录对应。

## 结果的区别
| 结果 | 应如何理解 |
| --- | --- |
| 成功导入 | 有实际 PDF，且保存结果可核对 |
| 重复 | 同样内容可能沿用已有文件，不覆盖已有题录 |
| 无公开全文 | 题录存在，但没有找到当前可公开读取的 PDF |
| 访问受限 | 网站需要订阅、登录、验证码或其他授权 |
| 传输失败 | 超时、网络或服务异常；不等于论文不存在 |

机构订阅和登录授权需要从论文网站按其允许的方式获取。不要把出版社登录页另存为 `.pdf`，也不要绕过访问控制。

## 取消与重试
取消会停止未完成工作，但不表示已经保存的文件会被删除。批量导入中，一篇失败也不意味着其他篇都失败；逐项查看结果后再重试，避免盲目重新下载整批。

## 大文件与隐私
最新原生全文下载链路有 256 MiB 上限，并在取消时清理半成品。浏览器预览的链路和限制可能不同，不把这个数值推广到所有入口。配置的文献服务密钥不应随出版社或 PDF 跳转转发。

网站可达性会变化，文档中的一次成功样例不保证今天仍然成功；遇到问题时记录去掉敏感查询参数的来源地址及错误状态。
