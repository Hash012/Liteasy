这份手册由 0.1.28 的材料包整合并补充后续功能说明，不是对某个安装包已发布、已签名或已通过 Windows 验收的保证。取得安装包时，应同时取得维护者提供的版本号和对应构建信息。

## 安装前
确认来源是项目维护者指定的发布渠道，文件对应你的操作系统。不要把源码 ZIP、GitHub 构建日志或浏览器预览地址当成桌面安装包。当前仓库以 Windows NSIS 安装包构建为明确分发链路；其他系统有源代码并不等于已有同等安装交付。

## 首次安装与检查
1. 按安装程序提示完成安装，再启动 Liteasy。不要为绕过警告而全局关闭系统安全功能；来源、签名或文件完整性有疑问时先向维护者核对。
2. 打开 **设置 → 文件与存储 → 数据保存位置**，记录当前路径。已有数据与自定义位置可能不是新安装的默认位置。
3. 先导入一个非敏感 PDF，测试双击阅读、创建并保存笔记。需要 AI 时再单独测试模型。
4. 记录“应用版本、安装包来源、操作系统”，供以后排错；无法从界面确认版本时，保留安装包名并请维护者核对，勿凭手册版本推断。

## 升级已有安装
先保存所有编辑，等待生成和同步结束，做独立备份，再运行维护者确认的升级包。升级后依次检查原文、批注、笔记、白板及数据路径。不要先卸载、清空数据或覆盖旧库来尝试修复。

多设备使用 WebDAV 时，应先确认客户端兼容同一同步格式。应用版本与数据格式版本不是同一概念；旧客户端遇到未知格式应停止，不能手改版本字段强行打开。

## 浏览器预览不是安装版替代品
预览版用于前端体验与开发检查。它的数据存储、文件授权、密钥持久化和 CORS 限制与桌面不同；本机 MCP、原生迁移等功能不能仅凭浏览器页面出现按钮就判定可用。
