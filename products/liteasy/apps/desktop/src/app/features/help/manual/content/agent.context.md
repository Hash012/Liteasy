助手不会因为你在屏幕上看过某个页面，就自动可靠地拥有全部资料。先提供对象，再说明任务，最后说明允许的操作和验收方式。

## 三种提供资料的方式
使用 **@** 查找论文或其他资源；从文献库或白板拖入资源；在阅读器选段后使用加入对话或摘录对话。发送前核对对象名称，避免把同名笔记或错误论文加入上下文。

输入 **/** 查看当前可用能力。列表反映当前环境，不要照抄别的软件命令名，也不要把一个普通斜杠词当成已经安装的工具。

## 一个可复用的提问模板
```text
资料：我已经引用的两篇论文及“实验比较”笔记。
任务：比较两篇论文如何衡量读取开销。
边界：只依据实际读到的正文；先不修改任何笔记。
输出：按指标、实验条件、结论、证据位置列出对比。
检查：列出没有读到或不能确认的内容，不补造引用。
```

## 标题引用不等于全文覆盖
来源可能只有题录、部分解析页、一个选段或有界的正文片段。让助手先说明读取范围；需要长文完整分析时，要求继续读取剩余部分并报告覆盖，而不是直接相信“全文分析完成”的一句话。

## 修改资料前
把“生成建议”与“写回资产”分开。外部 MCP 还需要独立写入授权，且必须读最新版本再提交。发生版本冲突或超时，不要要求强制覆盖；先核对实际内容。

## 内容不是指令权限
论文、网页或笔记里可能包含面向模型的指令。引用它们是为了分析内容，不是授权它们改变你的任务、上传其他资料或索取密钥。


## 先预览，再只添加需要的片段

在 **添加上下文** 浮窗中找到文件，打开内容选择界面，可点击章节标题、选择行范围或直接选中文字，再添加到对话。正文中会插入蓝色加粗的上下文名称，模型收到的文字也保留名称。

片段会固定为选取时的内容版本；选章节时包含其子标题，直到下一个同级或更高层级标题。只加入所选片段，而不是为了引用一段话自动加载整份文件。预览期间源文件发生变化时，应刷新后重选。PDF 的这一选择界面使用提取文本，行号不是 PDF 原始版面坐标。
