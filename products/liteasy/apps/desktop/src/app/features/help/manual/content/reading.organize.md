## 分类与查找
在文献库右键文件，设置分类与标签。用库顶端的搜索框和筛选入口按作者、年份、学科或标签缩小结果。目录适合确定位置，标签适合表达一篇论文跨多个主题的关系。

先确认当前是否仍有筛选条件。“不显示”可能是被过滤，不应立即重新导入或删除索引。

## 移动文件
把条目拖到目标目录，看到“松开即可移入”等反馈再释放。应用应在磁盘移动成功后更新工作区；出现错误时，不要仅根据拖动动画认定文件已经搬走。核对目标目录和原位置后再重试。

已有标签页或外部程序正在使用文件时，先保存并关闭相关编辑。不要绕过目录授权，把文件拖到不属于当前本地库的路径后再手改内部记录。

## 更换图标
在文件、目录或论文附属资源的右键菜单选择 **更换图标**，选 Fluent 图标或单个 Emoji，也可恢复默认。图标是识别辅助，不改变文件类型或解析能力。

图标偏好按本机账号和文献库保存。应用内移动或重命名目录会维护相关映射；在操作系统里直接重命名目录，不保证图标偏好自动跟随。

## 题名不是文件名
确认论文元数据后，库里可能显示正式论文标题，而磁盘文件仍保留原来的名字。不能仅因为两者不一样就判断文件错配；应核对 DOI、作者、年份和正文。需要修正学术信息时，使用元数据入口，而非只给文件改名。

## 组合搜索条件
在全局搜索框下展开 **筛选条件**，或点击文献库、笔记与产物等搜索框旁的 **高级检索条件** 按钮，即可分别选择包含、排除的标签、格式和类别。每个字段支持多选、搜索候选，也可输入自定义值后按回车或点击加号添加，无需记住检索语法。已选条件显示为小标签，点击叉号可逐项移除；**清除筛选条件** 会保留关键词和正则表达式。

多个包含标签须同时满足；多个格式或类别分别匹配任意一项，排除条件始终生效。文献库原有标签筛选中，点击标签表示包含，旁边的减号表示排除。文献库的检索字段还可切换到 **仅名称**，不再匹配作者和摘要。

也可直接输入条件，或把常用组合保存在全局搜索中：

| 查询 | 含义 |
| --- | --- |
| `记忆 tag:精读 -tag:翻译` | 搜索记忆，必须持有“精读”且不能持有“翻译”标签 |
| `format:pdf format:epub -type:book` | PDF 或 EPUB，排除类别为图书的条目 |
| `type:note -tag:"AI 生成"` | 笔记类别中，排除标记为 AI 生成的内容 |
| `/memory\s+\d+/i format:md` | 在 Markdown 文件中用正则匹配 memory 和后面的数字 |

多个包含标签必须同时持有；多个格式或类别满足任一项即可。标签值精确匹配，带空格时用引号包围。类别使用 `book`（图书）、`note`（笔记）、`journal-article`（期刊）、`conference-paper`（会议）、`preprint`（预印本）等，筛选浮窗中提供候选。没有类别信息的条目不会被推断成期刊或图书。

正则支持 `/表达式/i`、`re:"表达式"`，以及 `i`（忽略大小写）、`m`（多行）、`s`（点匹配换行）标记。不支持环视与反向引用；无效表达式会显示提示，不会执行。普通文本默认忽略大小写，PDF 查找栏可单独指定区分大小写和全词匹配。

## 正文定位
全局搜索可选择正文、笔记或批注范围；文件名命中不会作为每个正文段落的命中。点击结果会打开来源并高亮实际匹配文字，批注命中会展开对应批注。高亮是临时显示，不修改原文件。

在 PDF、电子书和论文阅读模式中，使用各自的查找入口；在 Markdown 编辑区按 **Ctrl+F** 打开正文检索，输入后按 Enter、Shift+Enter 或箭头按钮跳转。它们也支持上述组合条件；标签和格式条件针对当前文件，条件不符时正文结果为空。

全局搜索只覆盖当前账号可访问且已提取的内容，达到容量上限、扫描 PDF 未提取或来源暂不可读时会显示覆盖说明。不会为了搜索自动调用 AI 或上传正文。新增或修改标签会更新检索索引，阅读进度、焦点变化不会触发重建。
