## 何时需要账号
本地阅读与自备 API key 模式可以不登录 Liteasy。选择云端模型、社区、云端元信息同步或其他受账号控制的服务时，需要相应服务真实可用及自己的权限。

仓库没有通用的固定测试账号。请通过实际部署提供的注册／登录流程使用自己的账号，不要索取或复用 README 中的演示密码。

## 检查同步和共享入口
在 **设置 → 同步与备份 → 文献元数据同步** 查看题录的云端同步状态；在 **共享批注** 中核对相关服务配置。不要把“题录已同步”理解为 PDF、所有批注和完整库都已传到云端。

共享内容前检查可见范围、接收方、服务地址和权限。个人笔记、团队评论、公开批注及单论文评论 Review 的边界不同，不能互相替代。

## 服务不可用时
保留本地资料，先检查当前账号、安装环境和实际服务状态。开发服务只用于本地开发；代码里存在 PostgreSQL、S3 或身份服务实现，不代表生产环境已经完成部署与验收。

不要向陌生地址上传账号凭据，也不要把 Desktop 的登录 token 复制给其他产品或客户端。使用产品提供的登录流程，具体组织权限问题由该部署的维护者确认。

## 切换账号
先保存编辑并等待任务完成，再切换账号。不同账号的数据和连接有隔离要求；本机 MCP 或设备任务等授权可能被撤销，需要重新确认。不能因为换回旧账号就假定之前的临时授权仍然有效。
