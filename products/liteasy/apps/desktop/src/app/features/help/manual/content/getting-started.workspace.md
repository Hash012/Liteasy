文献库负责找到资源，中间区负责打开与编辑，AI 对话负责围绕已提供的资料提问。底部元信息描述当前选中的对象，不一定就是你正在阅读的标签页。

## 起始页与任务布局
桌面起始页的 **打开 Markdown 原文件**（Ctrl／Command + O）直接引用所选笔记；编辑并保存会写回原文件。**连接笔记文件夹**（Ctrl／Command + Shift + O）保留原目录层级，不复制或上传内容。PDF、电子书目前仍从文献库复制导入；不要把它与原位置打开混淆。

**阅读布局**收起周边面板；**研究布局**展开文献库和助手；**处理布局**打开已有运行记录，不会启动模型或任务。**恢复自定义布局**恢复本次切换前的面板展开状态；这些操作保留页面、位置和草稿，不进入 F11 全屏模式。快捷操作菜单也提供相同入口。

## 打开和切换
1. 在文献库单击条目，先核对底部题名等信息；双击打开正文。
2. 点击中间区已有标签回到相应文档。查找已打开页面可用 **切换活跃页面**；找以前访问的页面可用 **回溯历史页面**。
3. 论文左侧的 **+N** 展开附属笔记、白板或产物。关闭标签不等于删除这些资料。
4. 需要更大文献库视图时，可双击最左侧的文献库按钮打开大浮窗；选择论文或附件后回到工作区。

## 专注阅读
从顶栏 **布局 → 沉浸阅读** 进入，或连续三击文件条目／阅读标签。三击只是捷径，不必学习它才能使用。**F11** 切换全屏专注；将鼠标移到屏幕边缘可临时展开被收起的工具。

按 **Esc** 退出沉浸阅读；有菜单或对话框时，会先关闭它们。退出后原有分栏、阅读内容和未发送草稿应保留。草稿保留不等于已经保存到磁盘，离开应用前仍需保存编辑。

## 找不到工具时
用左侧活动栏重新打开文献库、AI、设置或帮助。按 **F1** 找回帮助；关闭所有中间标签后会出现开始页。不要通过清空工作数据来恢复一个被关闭的面板。

## 小屏使用建议
先保留“正文＋一个辅助面板”，而不是同时展开所有工具。阅读时用批注记录疑问，集中处理时再展开 AI 和白板；这是工作习惯建议，不是应用对窗口数量的限制。
