“在本机保存资料”“不登录 Liteasy”“不联网”“不把资料交给外部模型”是四件不同的事。选择最少满足任务的配置即可。

## 四条常用路线
| 你的目标 | 需要什么 | 不代表什么 |
| --- | --- | --- |
| 阅读已在本机的 PDF、笔记 | 本地文件及读取授权 | 不代表所有扫描件已识别 |
| 用自己的模型问答 | 可用模型连接；远程服务通常需联网 | 不要求 Liteasy 账号，但可能有模型费用 |
| 从文献服务获取题录和推荐 | Crossref、OpenAlex 或 Semantic Scholar 等服务配置及网络 | 不等于模型连接；不等于全文可下载 |
| 在设备间同步 | 自己的 WebDAV 服务、账号和选择的同步范围 | 不是实时协同编辑，也不是独立备份 |

## 无需 Liteasy 登录的起步方式
先使用本地资料库，再在模型设置中配置自备 API key；文献供应商选择外部文献服务时，题录与推荐沿用对应连接，不必为了它们先登录 Liteasy。选择 Liteasy 云端后，才进入相应云服务和账号权限边界。

## 关于离线
已经下载的正文和随应用打包的帮助可离线阅读。远程模型、题录更新、全文下载及远端同步需要网络。本地推荐缓存只能复用已缓存的结果，不能保证断网时获得新的检索结果。

自备密钥不等于本地模型。仅当你确实配置并运行了本机模型服务时，模型请求才可能留在本机；外部 MCP 客户端使用谁的模型，也由该客户端的配置决定。

## 建议的配置顺序
本地阅读成功 → 需要 AI 时测试模型 → 需要发现论文时配置文献服务 → 做备份 → 最后启用同步和扩展。每次只新增一个变量，失败时容易判断是哪条链路出了问题。
