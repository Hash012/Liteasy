模型返回了一段流畅文字，只能证明请求产生了结果。你仍要判断资料是否匹配、读取范围是否充分，以及结论是否得到证据支持。

## 四项最小核验
| 检查 | 具体做法 |
| --- | --- |
| 来源 | 随机挑一条结论，回到对应论文或选段，而非只核对标题 |
| 覆盖 | 询问已读页面、片段与缺失部分，尤其是长文、扫描件和附件 |
| 数值 | 核对单位、比较基线、实验硬件、数据规模及“提高到／提高了” |
| 推断 | 区分作者结论、你的理解和 AI 建议；不确定时保留未知 |

## 让错误容易被发现
先问一个有明确答案的小问题，再逐步扩展。对比多篇论文时先统一维度和实验条件；让模型列出无法比较的项目，而不是强行填满表格。

可以追问：“请指出上一段中哪些内容能直接在原文找到，哪些是你的推断。没有读到的证据不要给出页码。”模型的自我检查有帮助，但仍不是独立事实证明。

## 分享与提交前
保留原文引用，检查未公开资料和个人信息。对外展示的图表、演示和研究笔记，特别核对因果关系、性能数字、论文身份与版本。不把 AI 输出中的虚构引用带入论文或报告。

## 出错后保留什么
记录资源、所用模型、问题、本次提示词和最小错误片段，去掉密钥及敏感正文。将“模型回答错了”与“应用没有正确读入资料”分开，维护者才能判断需要修改哪一层。
