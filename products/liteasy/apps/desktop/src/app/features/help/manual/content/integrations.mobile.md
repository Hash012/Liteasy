> 此流程要求业务 API、身份客户端和设备协议已正确部署。当前开发记录仍要求真实“手机—身份服务—API—桌面”链路单独验收；不要把设置入口当成生产功能已开通。

## 配对条件
两端必须使用同一个 API 和同一身份账号。桌面需通过原生系统浏览器 OAuth 登录；浏览器预览和旧开发密码会话不提供同等原生设备身份。桌面要保持运行并联网。

## 配对
1. 在桌面打开 **设置 → 同步与备份 → 手机与设备**，启用手机任务并给桌面命名。
2. 生成配对码，在手机的 **Desktop tasks** 页面输入八位码；在五分钟内完成，配对码只用一次。
3. 先用无敏感内容的测试文档验证；任意一端都可解除配对。

## 当前允许的任务
打开文档会核对本地身份和 PDF 哈希；提取文字使用已有文字层，不承诺 OCR；总结需要独立开关和当前桌面模型连接；同步文献库调用已经配置的 WebDAV 流程，冲突仍在桌面解决。

任务队列不会替你把 PDF 上传到另一台设备。先同步相同逻辑文档及附件版本，仅有相同文件名不够。找不到匹配文件时任务可能等待，不应随意打开同名但不同的文件。

## 离线、取消与未知结果
关闭桌面或关闭任务会停止新的执行，手机提交可能继续排队；不能唤醒已关机电脑。取消是协作式的，已完成操作、正在提交的同步或已发生的模型费用不会撤回。

重启后遇到未知执行结果，先检查文档、同步状态和服务商使用记录，再考虑发新任务，避免重复执行。
