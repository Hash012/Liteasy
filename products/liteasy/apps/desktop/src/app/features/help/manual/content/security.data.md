## 按功能查看数据去向
| 操作 | 可能发送的内容与接收方 | 需要单独注意 |
| --- | --- | --- |
| 本地阅读、已保存笔记与离线帮助 | 在本机处理已有内容 | 这不能代表其他已开启功能也离线 |
| 自备远程模型问答 | 问题及实际提供的上下文发往选定模型端点 | 不要求 Liteasy 账号；模型服务商政策另行适用 |
| 文献元信息与推荐 | 查询与题录线索发往选定文献服务 | 不等于全文上传或模型聊天 |
| 增强推荐外部语义服务 | 取决于所选输入和明确外发授权 | 笔记、批注、画像外发默认关闭 |
| WebDAV 同步 | 选中类别发往你配置的服务器 | 对话、偏好和画像类别默认开启；密钥另选 |
| 本机资产 MCP | 授权资产交给本机客户端 | 客户端还可能把内容发给其模型 |
| 评论 Review | 主动共享的单论文个人文字评论快照 | 已接收内容不可因停止共享撤回 |
| 手机任务 | 受控任务与结果经过对应业务服务 | 文档任务不通过队列上传 PDF 本身 |

## 密钥与资料不是同一保护对象
桌面模型密钥保存在系统凭据库；这不表示所有笔记、PDF 和同步对象都使用同样的加密方式。WebDAV 密钥同步有独立加密包，不能据此宣传整个资料库端到端加密。

## 敏感资料的最小配置
先关闭不需要的同步类别、行为记录和外发权限，只对明确选中的非敏感片段验证功能。未公开论文、个人信息、单位内部材料和受合同限制的内容，发送前按自己的授权要求处理。

## 本手册不承诺的事项
本包没有对所有云服务保留期限、数据处理条款、网络代理和第三方扩展做完整审计，也不作“绝不泄露”“任何模式都不联网”的保证。实际接收方及权限应在操作前确认；凭据疑似泄露需在服务商处轮换或撤销。
