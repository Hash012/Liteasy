## 创建第一块白板
可以在论文右键菜单中创建论文白板，让它出现在该论文的附属资源中。给白板起一个问题式名称，例如“这两种索引的取舍”，比“白板 1”更便于检索。

在空白处双击创建笔记卡片，输入一个具体问题或观点。单击卡片选择，双击进入编辑；卡片支持拖动、调整尺寸和连接。先用两三个卡片验证保存，再扩展内容。

## 常用操作
| 目标 | 操作 |
| --- | --- |
| 框选卡片 | 在空白处拖动 |
| 加选 | 按住 Shift 继续选择 |
| 全选 | Ctrl／Command + A |
| 移除所选卡片 | Delete 或 Backspace |
| 平移视图 | 空格＋拖动，或中键拖动 |
| 缩放 | Ctrl／Command＋滚轮 |
| 适应内容 | Shift + 1 |

编辑文本时先退出输入状态，再使用删除或全选等白板操作，避免把预期的文字编辑变成卡片操作。快捷键以焦点所在区域和当前界面提示为准。

## 让连线有含义
用卡片承载“问题、证据、解释、待验证”，用连线表示你认定的关系。连线不自动证明两个观点有因果关系；论文引用和页码应保留在卡片文字中。

## 保存与边界
重新打开白板检查卡片和连接。当前画布不是对所有无限坐标或所有第三方 Canvas 特性的完整实现。移除白板上的卡片，也不应被当成删除对应原论文；涉及源资产删除时，另外核对操作目标和确认信息。
