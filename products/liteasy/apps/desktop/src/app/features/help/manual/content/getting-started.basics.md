完成这条路线后，你应当能重新打开自己的论文，找到一条已保存的批注或笔记，并知道 AI 使用了哪些资料。先选一篇可复制文字、没有敏感信息的小 PDF；不要用整个文献库做第一次测试。

## 先完成不依赖 AI 的部分
1. 点击最左侧的 **文献库**，选择标题旁的 **导入文件**，导入测试 PDF。
2. **单击**条目查看底部元信息；**双击**条目在中间阅读区打开。
3. 选中一小段原文，使用选段工具栏添加高亮或文字评论。没有可靠选区时，先尝试复制文字，勿反复生成空批注。
4. 在文献库右键该论文，创建有名称的 Markdown 笔记，例如“首次阅读”。写下“研究问题、关键结论、我的疑问”，并保存。
5. 展开论文左侧的 **+N** 附属资源入口，确认能找到笔记。切换到其他页面，再返回检查内容。

## 再连接 AI
1. 打开 **设置 → AI 与助手 → 模型与连接**。选择自备 API key，填写服务商、API 基础地址、模型 ID 和自己的密钥。
2. 点击 **保存并测试**。这会发送真实的短请求，可能产生服务商费用。只有看到成功响应才继续。
3. 点击左侧机器人图标打开 AI 对话，用 **@** 选择刚导入的论文，确认它出现在上下文中，再输入问题。
4. 试问：“请只根据已提供的内容说明研究问题和一个关键结论；引用原文或页码。没有读到的内容请明确说明。”
5. 回到原文核对一处引用，把自己确认的理解写进笔记，而不是把整段 AI 回答当作已经证实的结论。

## 你应该看到
本地阅读、已保存笔记和模型测试是三个独立结果。模型失败不代表 PDF 丢失；PDF 打开也不代表模型能读取全部页面。关闭并重开已保存笔记，内容仍在，才算完成保存检查。

## 卡住时
没有 API key 也能先完成本地阅读。模型连接问题搜索“模型连不上”；原文不能选中搜索“扫描件”；不知道资料存在哪搜索“数据保存位置”。按 **F1** 可重新打开本手册。
