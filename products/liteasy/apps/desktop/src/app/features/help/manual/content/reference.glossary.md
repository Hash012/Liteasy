| 术语 | 在 Liteasy 使用中的意思 |
| --- | --- |
| 文献库 | 查找和组织文献及本地文件的工作入口；不是所有外接目录的同义词 |
| 元数据／题录／元信息 | 标题、作者、年份、DOI 等描述信息，不是论文全文 |
| 全文可用 | 该任务拥有可读取的正文来源；与只获取到题录不同 |
| 批注／评论 | 与阅读材料关联的标记和文字；纯高亮与文字评论范围不同 |
| 论文附属资源 | 论文下的笔记、白板等关联内容，可由 +N 展开 |
| 薄读 | 用 AI 建立论文概览与阅读起点，不是已完成全文事实核验 |
| 产物 | 生成的提纲、演示、导图或对比表等内容；不自动等于某种导出文件 |
| 上下文 | 本次实际提供给助手的资料范围，可能是整项资源或有界片段 |
| 画像 | 用于表达兴趣或行为的信号；本地记录、外发和同步分别控制 |
| API 基础地址 | 服务入口及必要版本路径，不是随意追加的完整操作 URL |
| 系统凭据库 | 操作系统管理的秘密存储，区别于普通设置文件 |
| WebDAV | 访问你配置的远端存储的协议；不是所有应用同步格式互通的保证 |
| 快照 | 某次捕获时的一份内容，不会自然跟随之后的每次修改 |
| 修订／revision | 判断你读到的版本是否仍是最新版本的标识 |
| 版本冲突 | 提交依据的版本落后于当前版本，需要比较或合并 |
| MCP | 外部 AI 客户端访问受控工具与资产的协议；不等于模型本身 |
| STDIO | 通过本机进程标准输入输出通信，不是对公网开放的 HTTP 地址 |
| Liteasy Path | 应用内部定位资源的路径或链接，不等于任意操作系统磁盘路径 |
| 幂等重试 | 同一操作按约定重试时尽量不重复产生效果；有会话和参数边界 |

## 两个特别容易混淆的版本
应用版本表示你运行的软件发布；数据格式版本表示文件或同步协议的结构。应用降级不保证可以读取新版数据，不能手改格式版本来绕过检查。

## 阅读本手册的方法
不知道怎么操作时搜索任务词，例如“添加笔记”；不知道为什么时搜索概念词，例如“版本冲突”。不必先背完术语表才能开始阅读一篇论文。
